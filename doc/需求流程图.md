## 一、主流程总览

```mermaid
flowchart TD
  Start([进入小程序]) --> Home[首页]
  Home -->|今天菜场有什么| Gate{有待确认的近期菜?}
  Home -->|记一下吃了什么| Record[记录页<br/>手动/语音；拍照后置]
  Home --> Mine[我的页<br/>画像/忌口/搭配/城市]

  Gate -->|有| Confirm[进场确认弹层<br/>锚点菜默认不勾选]
  Gate -->|无| Input
  Confirm -->|确认吃过 → 写入记录| Input[输入页<br/>时令主列表全选 + 四季常见已计入 + 当次场景]

  Input -->|确认| Rec[推荐页<br/>1~3 方案 / 换一批 / 可以·不行]
  Rec -->|可以| List[购买食材页 ★主广告位<br/>主料优先·勾选已买]
  Rec -->|查看购买清单| ListPreview[购买食材页 预览<br/>accepted=false]
  Rec -->|换一批且免费次数用尽| Reward[[激励视频 · 辅广告位]]
  Reward --> Rec
  Rec -->|不行| Rec

  ListPreview -.->|可再点可以正式采纳| List
  List --> Stall[线下摊位挑真菜<br/>对照清单·停留数十秒~数分钟]
  Stall --> List

  Record --> Home
  List -->|稍后/回首页| Home
```

## 二、进场 → 出方案（无主广告）

> 此段为决策链路，**不放插屏 / 不强插广告**，避免打断菜场短决策。

```mermaid
flowchart LR
  subgraph 决策区["决策区 · 默认无广告"]
    A[进场确认弹层] --> B[确认可选食材<br/>时令全选；四季常见默认计入]
    B --> C[当次场景<br/>类型/人数/搭配/几顿]
    C --> D{类型?}
    D -->|日常| E[带出默认人数+搭配<br/>用画像忌口]
    D -->|非日常| F[人数后推荐搭配<br/>当次忌口硬排除]
    E --> G[推荐引擎]
    F --> G
    G --> H[推荐页]
  end
```

**当次场景补充**：

| 类型 | 人数 / 搭配 | 忌口 |
|------|-------------|------|
| 日常 | 自动带出默认，可改 | 家庭忌口硬排除 + 成员忌口软约束 |
| 非日常 | 不预填；填人数后推荐搭配 | 当次本场忌口硬排除；不写回画像 |

## 三、推荐 → 清单 → 摊位采购（广告主战场）

```mermaid
flowchart TD
  H[推荐页] --> Choice{用户操作}
  Choice -->|可以| L1[购买食材页<br/>accepted=true]
  Choice -->|查看购买清单| L0[购买食材页<br/>accepted=false · 预览]
  Choice -->|换一批| Limit{免费次数是否用尽?}
  Limit -->|否| H
  Limit -->|是| AD2
  AD2[["广告位 B · 激励视频<br/>看完 +N 次换一批"]] --> H
  Choice -->|不行| Reason[可选原因反馈] --> H

  L1 --> AD1
  L0 --> AD1
  AD1[["广告位 A · 原生模板 ★主位<br/>清单底部 / 列表间隙<br/>日常 1 条 · 非日常可 2 条"]]
  AD1 --> Buy[用户在摊位挑真菜<br/>眼睛看货 · 手机亮着清单]
  Buy --> Check[勾选已买] --> Buy

  Cover[["广告位 C · 封面广告 · 辅<br/>回前台时低频"]] -.-> L1
```

## 四、广告曝光位说明

### 4.1 位次一览

| 代号 | 页面 / 时机 | 形态 | 优先级 | 阶段 |
|------|-------------|------|--------|------|
| **A** | **购买食材页**（摊位对照采购时） | 原生模板：底部 / 列表间隙。日常 1 条；**非日常可 2 条**（仍间隙，不插屏） | ★ 主位 | 流量主达标后 |
| **B** | 推荐页「换一批」次数用尽 | 激励视频 | 辅 | 可选，与 A 同期或稍后 |
| **C** | 从后台回前台进入清单相关页 | 封面广告 | 辅 · 低频 | 可选 |
| — | 进场确认 / 输入页 / 出方案前 | 插屏等 | ✗ 明确不做 | — |
| — | 清单对照时全屏挡住清单 | 插屏 | ✗ 明确不做 | — |

### 4.2 主位 A — 为何钉在购买食材页

1. 用户点「可以」（或查看清单）后，开始**线下摊位挑真菜**，会反复看清单。  
2. 单次停留常有十几秒到数分钟，适合**伴随式曝光**，不要求一直点 App。  
3. 决策已完成，广告不打断「确认食材 → 出方案」。  
4. 清单支持「已买」勾选，拉长停留 = 拉长有效曝光。  
5. **非日常**清单更长、采购更久，同一主位允许加第 2 条原生；日常不加。会员后 A（含第 2 条）一并隐藏。

### 4.3 页面 × 广告矩阵

| 页面 | 广告 | 备注 |
|------|------|------|
| 首页 | 无 | 保持入口干净 |
| 进场确认弹层 | ✗ | 禁止插屏 |
| 输入页（App 勾选食材 + 场景） | ✗ 主路径无广告 | 停留短，且非摊位采购 |
| 推荐页 | 仅 B：次数用尽激励视频 | 不在方案卡片中部插屏 |
| **购买食材页** | **A 原生（必做容器）**：日常 1 条，非日常可 2 条；C 封面可选 | 线下选菜时长主战场；第 2 条仅非日常 |
| 记录页 / 我的 | 无 | 后期另议，非当前定稿 |

### 4.4 会员后的变化（阶段 2）

```mermaid
flowchart LR
  M[会员用户] --> Free[去广告：隐藏 A/C]
  M --> Extra[更多换一批等 · 可不看激励 B]
  Free --> List[清单页仍完整可用]
```

非会员：继续曝光 A（及可选 B/C）。日常主链路功能不设付费墙。

## 五、饮食记录支线（无广告）

```mermaid
flowchart TD
  Home[首页「记一下」] --> R[记录页]
  Mine[我的 → 历史] --> R
  R --> M1[手动]
  R --> M2[拍照（后置·不展示）]
  R --> M3[语音]
  M1 --> Log[(meal_logs)]
  M2 --> Log
  M3 --> Log
  Next[下次进场] --> Dedup[近期推荐 − 最近一次搭配后已记录]
  Dedup --> Confirm[进场确认弹层]
  Log -.-> Dedup
```

采纳推荐**不**自动写记录；进场确认与主动记录才写入。

## 七、状态速查（研发对照）

| 步骤 | 关键状态 / 产出 |
|------|----------------|
| 进场确认 | 写入 `meal_logs`（来源：进场确认） |
| 输入页确认 | `ingredients[]` + 场景参数（类型、人数、搭配、顿数、当次忌口） |
| 推荐 | `recommendations[]`；换一批=会话内换菜；不行=弹原因（可不选）+ 长期降权 |
| 可以 | `accepted=true` → 购买食材页 + **广告位 A**（非日常可第 2 条） |
| 查看清单 | `accepted=false` → 同页预览 + **广告位 A**（可曝光，非正式采纳；非日常同样可 2 条） |
| 摊位采购 | 用户离线动作；App 停留清单页累计曝光时长 |
| 记录 | 手动/语音/下次进场确认（拍照后置） |
