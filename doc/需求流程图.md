## 一、主流程总览

```mermaid
flowchart TD
  Start([进入小程序]) --> Home[首页]
  Home -->|今天菜场有什么| Gate{有未处理的待确认菜?}
  Home -->|记一下吃了什么| Record[记录页<br/>手动/语音；拍照后置]
  Home --> Mine[我的页<br/>画像/忌口/搭配/城市]

  Gate -->|有| Confirm[进场确认弹层<br/>默认不勾选·确认或跳过后下次不弹]
  Gate -->|无| Input
  Confirm -->|确认勾选 / 跳过<br/>标记已处理| Input[输入页<br/>时令主列表全选 + 四季常见已计入 + 当次场景]

  Input -->|确认| LiteGate{日常且忌口未填?}
  LiteGate -->|是| Lite[轻量补全弹层<br/>忌口+爱吃什么·可跳过]
  LiteGate -->|否| Rec
  Lite -->|保存 / 跳过| Rec[推荐页<br/>1~3 方案 · 右下角食材一行<br/>换一批·不行 · 方案旁「去买菜」]
  Rec -->|去买菜| List[购买食材页 ★主广告位<br/>按分类·每行2个·勾已买<br/>底部菜谱弹层]
  Rec -->|换一批且免费次数用尽| Reward[[激励视频 · 辅广告位]]
  Reward --> Rec
  Rec -->|不行| Rec

  List --> Stall[线下摊位挑真菜<br/>对照清单·停留数十秒~数分钟]
  Stall --> List

  Record --> Home
```

## 二、进场 → 出方案（无主广告）

> 此段为决策链路，**不放插屏 / 不强插广告**，避免打断菜场短决策。

```mermaid
flowchart LR
  subgraph 决策区["决策区 · 默认无广告"]
    A[进场确认弹层] --> B[确认可选食材<br/>时令全选；四季常见默认计入]
    B --> C[当次场景<br/>类型/人数/搭配/几顿]
    C --> D{类型?}
    D -->|日常| E[成员派生大/小/老<br/>可改搭配·用画像忌口]
    D -->|聚会| F[本场大/小/老<br/>自动 combo·不露荤素汤<br/>本场忌口硬排除]
    E --> Lite{忌口未填?}
    Lite -->|是| LiteSheet[轻量补全弹层可跳过]
    Lite -->|否| G
    LiteSheet --> G[推荐引擎]
    F --> G
    G --> H[推荐页]
  end
```

**当次场景补充**：

| 类型 | 人数 / 搭配 | 忌口 |
|------|-------------|------|
| 日常 | 成员派生大/小/老；`defaultCombo` 可改 | 家庭忌口硬排除 + 成员忌口软约束 |
| 聚会 | 本场大/小/老（不预填）；`suggestPartyCombo` 自动，页上不改 | 本场忌口硬排除；不写回画像 |

## 三、推荐 → 清单 → 摊位采购（广告主战场）

```mermaid
flowchart TD
  H[推荐页] --> Choice{用户操作}
  Choice -->|去买菜（方案旁）| L1[购买食材页<br/>accepted=true · 该 planIndex]
  Choice -->|换一批| Limit{免费次数是否用尽?}
  Limit -->|否| H
  Limit -->|是| AD2
  AD2[["广告位 B · 激励视频<br/>看完 +N 次换一批"]] --> H
  Choice -->|不行| Reason[可选原因反馈] --> H

  L1 --> AD1
  AD1[["广告位 A · 原生模板 ★主位<br/>清单底部 / 列表间隙<br/>日常 1 条 · 聚会可 2 条"]]
  AD1 --> Buy[用户在摊位挑真菜<br/>眼睛看货 · 手机亮着清单]
  Buy --> Check[勾选已买] --> Buy

  Cover[["广告位 C · 封面广告 · 辅<br/>回前台时低频"]] -.-> L1
```

## 四、广告曝光位说明

### 4.1 位次一览

| 代号 | 页面 / 时机 | 形态 | 优先级 | 阶段 |
|------|-------------|------|--------|------|
| **A** | **购买食材页**（摊位对照采购时） | 原生模板：底部 / 列表间隙。日常 1 条；**聚会可 2 条**（仍间隙，不插屏） | ★ 主位 | 流量主达标后 |
| **B** | 推荐页「换一批」次数用尽 | 激励视频 | 辅 | 可选，与 A 同期或稍后 |
| **C** | 从后台回前台进入清单相关页 | 封面广告 | 辅 · 低频 | 可选 |
| — | 进场确认 / 输入页 / 出方案前 | 插屏等 | ✗ 明确不做 | — |
| — | 清单对照时全屏挡住清单 | 插屏 | ✗ 明确不做 | — |

### 4.2 主位 A — 为何钉在购买食材页

1. 用户点「去买菜」后，开始**线下摊位挑真菜**，会反复看清单。  
2. 单次停留常有十几秒到数分钟，适合**伴随式曝光**，不要求一直点 App。  
3. 决策已完成，广告不打断「确认食材 → 出方案」。  
4. 清单支持「已买」勾选，拉长停留 = 拉长有效曝光。  
5. **聚会**清单更长、采购更久，同一主位允许加第 2 条原生；日常不加。会员后 A（含第 2 条）一并隐藏。

### 4.3 页面 × 广告矩阵

| 页面 | 广告 | 备注 |
|------|------|------|
| 首页 | 无 | 保持入口干净 |
| 进场确认弹层 | ✗ | 禁止插屏 |
| 输入页（App 勾选食材 + 场景） | ✗ 主路径无广告 | 停留短，且非摊位采购 |
| 推荐页 | 仅 B：次数用尽激励视频 | 方案卡右下角一行食材摘要；完整清单仅「去买菜」进入；无查看清单预览；不在方案卡片中部插屏 |
| **购买食材页** | **A 原生（必做容器）**：日常 1 条，聚会可 2 条；C 封面可选 | 线下选菜时长主战场；第 2 条仅聚会；底部菜谱弹层不挡主勾选列表；**不另加回首页按钮** |
| 记录页 / 我的 | 无 | 后期另议，非当前定稿 |

### 4.4 会员后的变化（阶段 2）

```mermaid
flowchart LR
  M[会员用户] --> Free[去广告：隐藏 A/C]
  M --> Extra[更多换一批等 · 可不看激励 B]
  Free --> List[清单页仍完整可用]
```

非会员：继续曝光 A（及可选 B/C）。**日常与聚会**主链路均可免费走完，不以锁聚会作付费墙。

## 五、饮食记录支线（无广告）

```mermaid
flowchart TD
  Home[首页「记一下」] --> R[记录页]
  Mine[我的 → 历史] --> R
  R --> M1[手动]
  R --> M2[拍照（后置·不展示）]
  R --> M3[语音]
  M1 --> Log[(meal_logs)]
  M2 --> Log
  M3 --> Log
  Next[下次进场] --> Dedup[未处理锚点菜 − 锚点后已记录]
  Dedup --> Confirm[进场确认弹层<br/>确认或跳过 → 标已处理]
  Log -.-> Dedup
```

采纳推荐**不**自动写记录；进场确认与主动记录才写入。确认或跳过后同锚点不再弹。

## 七、状态速查（研发对照）

| 步骤 | 关键状态 / 产出 |
|------|----------------|
| 进场确认 | 确认/跳过 → 标 `entryConfirmHandled`；勾选则写 `meal_logs`（来源：进场确认）；下次同锚点不弹 |
| 输入页确认 | `ingredients[]` + 场景参数（类型、人数、搭配、顿数、当次忌口） |
| 推荐 | `recommendations[]`；换一批=会话内换菜；不行=弹原因（可不选）+ 长期降权；方案卡右下角一行食材 |
| 去买菜（方案旁） | `accepted=true` + 该 `planIndex` → 购买食材页（按分类、每行 2 个；底部菜谱弹层）+ **广告位 A**（聚会可第 2 条）；无预览入口 |
| 摊位采购 | 用户离线动作；App 停留清单页累计曝光时长；可开弹层按菜核对食材 |
| 记录 | 手动/语音/下次进场确认（拍照后置） |
