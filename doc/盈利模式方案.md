## 〇、最终方案（已定稿）

### 策略一句话

**先广告、后会员**：流量主达标后，用广告收入支撑更多能力建设；会员（方案 A）作为中期主现金流，等有一定使用数据再上。分佣 / B 端等保留为候选，不进当前主路径。

### 相对「聚会」收口：要不要改？

| 维度 | 结论 |
|------|------|
| **先广告后会员、主链路免费** | **不变**。采购对照清单仍是最强曝光位。 |
| **广告密度** | **规则不变，用语改「聚会」**：日常 1 条；**聚会可第 2 条**（桌菜更多、清单更长，仍间隙原生、不插屏）。不再按亲戚/朋友/节日分档——产品已无此分叉。 |
| **会员卖点** | **要调**：勿把「解锁聚会完整流程」当主权益。日常 / 聚会已是并列主路径，锁聚会等于砍半产品。会员改卖去广告、更高换一批、多顿/多成员、导出等；节日菜单等若日后恢复，再作增值。 |
| **方案 E（按次聚会/节日）** | **更往后**。节日入口已隐藏；聚会已是免费主路径的一部分，不宜单独按次卡关。保留候选，待节日/策划能力再议。 |

### 广告插入时机（核心约定）

这里的「选菜」指用户**在摊位上挑选真正的菜**（眼睛看货、偶尔看手机），不是 App 内勾选食材。

| 项 | 约定 |
|----|------|
| **主广告位** | 点「去买菜」之后的 **购买食材页（清单）** |
| **为何合适** | 用户沿摊位采购时会反复对照清单，单次停留常有十几秒到数分钟；屏幕可伴随曝光，不必打断挑菜动作 |
| **推荐形态** | 清单页底部 / 列表间隙 **原生模板**（日常 1 条；**聚会可加第 2 条**，仍走间隙、不插屏）；可选封面广告（回前台时，控制频次） |
| **可用但非主位** | 「换一批」等免费次数用尽后的 **激励视频**（看完加次数） |
| **明确不做** | 进场确认弹层插屏；出方案前的主流程插屏；挑菜对照清单时全屏挡住清单的插屏 |

### 与会员的衔接

- **日常与聚会**：确认食材 → 推荐 → 清单 → 记录，**两条主路径均可免费走完**（聚会含自动 `suggestPartyCombo`、本场忌口）。  
- 会员后置权益方向：去广告、更多换一批 / 多顿额度、更多家庭成员、导出等（细则见方案 A）；**不以「能用聚会」作付费墙**。  
- 上线会员的前置条件：有稳定回访与「采纳 → 进清单」等使用数据后再评估定价与权益包；另可观察聚会占比与清单停留，校准第 2 条广告与会员去广告价值。

### 分期落地（最终路径）

| 阶段 | 变现 | 要点 |
|------|------|------|
| **0 · MVP** | 无收费 | 埋点：采纳率、进清单停留、进场确认、换一批、回访、**日常/聚会占比**；清单页预留广告容器 |
| **1 · 流量主达标后** | **方案 C 为主** | 购买食材页原生（日常 1 条；聚会可 2 条）+ 可选激励换次数；用收入养菜谱 / 城市数据等能力 |
| **2 · 有使用数据后** | **叠加方案 A** | 轻会员；去广告 + 额度/家庭复杂度；**日常与聚会主链路仍免费** |
| **3 · 可选扩展** | 候选 B / D / E | 视数据与合作机会再开，不默认排期；E 待节日/策划能力再议 |

## 一、变现原则

1. **主链路免费、可完成**：确认食材 → **日常 / 聚会**推荐 → 购买清单 → 饮食记录，均可走完，不设付费墙（不以锁聚会作墙）。  
2. **变现贴线下采购时长**：广告出现在「已采纳、正在摊位对照买」的清单页，而不是打断出方案。  
3. **先广告养能力，再会员收现金**：不在无数据时推高门槛会员。  
4. **合规**：流量主按微信规则；分佣若未来启用须走正规联盟；不做敏感画像售卖。

## 三、方案详解

### 方案 C：微信流量主广告（阶段 1 主力 · 已定）

**怎么赚**：开通小程序流量主，按有效曝光与微信分成（比例以后台规则为准）。

**插入场景（已定）**：
- 用户在**线下菜场/摊位挑真菜**时，手机停留在购买食材清单页 → 底部或列表间原生广告伴随曝光。  
- **日常**：清单原生 **1 条**（底部或主料/调味分段间隙）。  
- **聚会**：桌菜通常更多（自动 combo 常 ≥ 人数档、可再 +1～2），清单更长，允许 **第 2 条**原生，仍放间隙或第二条底部，**禁止插屏**。屏占比克制，不要把清单挤没。不按亲戚/朋友/节日分广告档（产品已收口为单一聚会）。  
- 不是 App 内「勾选常见菜」页面；该页停留短，且尚未进入采购动作。

**形态优先级**：
1. 购买食材页原生模板（主；聚会可 2 条）  
2. 激励视频兑换「换一批」等次数（辅）  
3. 封面广告低频（辅）  
4. 插屏：默认关闭，尤其禁止盖住清单对照

**优点**：开发成本低；吃的是采购停留时长，与产品场景同构；聚会桌越大，停留与第 2 条曝光越合理。  
**风险**：未达流量主门槛前无收入；广告质量差会影响信任 → 频次与位置要克制；若实测聚会清单并不更长，可收回「第 2 条」仅留 1 条。  
**要点**：清单支持「已买」勾选、亮屏对照，拉长有效停留，等于拉长广告价值。

---

### 方案 A：会员订阅（阶段 2 主力 · 已定后置）

**怎么赚**：按月 / 季 / 年收取会员费（定价待有使用数据后定；行业常见参考：月 6–15 元，年 48–98 元）。

**免费 vs 会员（示例权益，可裁剪）**：

| 能力 | 免费 | 会员 |
|------|------|------|
| 日常推荐 + 换一批（有限次数 / 日） | ✓ | ✓ 更高额度 |
| **聚会**推荐（自动 combo、本场忌口）+ 换一批（有限） | ✓ 完整主流程 | ✓ 更高额度 |
| 购买清单 | ✓ | ✓ |
| 多顿规划（如 3 天多餐） | 基础 1 顿或限次 | 不限 / 优先 |
| 家庭成员数 | 如 ≤3 人 | 更多成员 |
| 高级搭配 / 菜式品类细调 | 基础 | ✓ |
| 导出清单、周菜单 | — | ✓ |
| 去广告（含聚会第 2 条） | — | ✓ |
| 节日专题菜单等（若日后恢复） | — / 试用 | ✓ 或并入 E |

**优点**：与家庭画像、多顿、去广告绑定；可预期现金流。  
**风险**：过早收费伤获客 → 故排在广告与数据之后；**勿用「锁聚会」换转化**——聚会已是主入口之一。  
**要点**：卖的是省事、额度与家庭复杂度，不是「能不能请客」；上线门槛 = 有稳定使用数据。

---

### 方案 B：食材 / 生鲜电商分佣（候选）

**怎么赚**：清单页跳转美团买菜 / 朴朴 / 盒马等，按成交佣金；或本地生鲜 CPS。

**产品落点（若启用）**：清单上「一键按清单线上买」弱入口，线下用户可忽略；不替代摊位采购主路径。

**为何暂列候选**：主场景是线下菜场对照清单；强推线上易与「摊位挑菜」心智冲突。有明确线上需求或合作后再评。

---

### 方案 D：品牌 / 本地 B 端合作（候选）

**怎么赚**：调味/厨电/预制菜场景露出；本地菜场「在售同步」SaaS；匿名聚合报告（合规脱敏）。

**为何暂列候选**：需销售与数据成熟度；过早接品牌易伤中立推荐信任。

---

### 方案 E：聚会策划增值 & 轻企业服务（候选 · 更靠后）

**怎么赚**：若日后恢复节日标签或「桌宴策划」深度能力，可按次付费或纳入会员；小 B 一周菜单订阅。

**为何暂列候选（且比原先更靠后）**：当前聚会已是免费主路径（自动搭配、不分子类型）；节日选择已隐藏，缺少「节日菜单」独立卖点。待有节日/策划差异化后再与阶段 2 会员合并评估；独立 B 端售后成本高，不单独立项于前期。

## 四、不推荐过早做的模式

| 模式 | 原因 |
|------|------|
| 自营生鲜电商 | 库存履约重，偏离决策工具定位 |
| 出方案前 / 清单对照时强插屏 | 破坏菜场短决策与对照采购体验 |
| 主推荐结果里强插商品 | 破坏中立搭配信任 |
| 无数据即推高价会员 | 伤获客与口碑 |
| 贩卖忌口等敏感画像 | 合规与舆论风险高 |
