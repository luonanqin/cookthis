# 城菜全国可见编辑

日期：2026-11-05  
状态：已定稿（对话确认方案 A / 实现方案 1）

## 目标

在 `tools/alias-editor` 增加「城菜」Tab：浏览 `recipes-builtin.json` 中带 `cities` 的菜，一键改为全国可见（`cities: []`），会话内可撤销。

## 规则

- 真源：`data/catalog/recipes-builtin.json`；只改命中条目的 `cities`，其它字段不动。
- 列表：仅 `cities.length > 0`；按城分组导航。
- 点菜名 → `cities = []`，进入「已改全国」区；再点 → 恢复本页记住的原 `cities`。
- 自动保存写回 builtin；「导出 for-import」触发/提示 `import-recipes.js` 生成 JSONL。
- 本期不做：多城编辑、改用料、从全国池加城。

## API

| 方法 | 路径 | 作用 |
|------|------|------|
| GET | `/api/city-recipes` | `{ byCity, promoted[] }` |
| PUT | `/api/city-recipes` | body `{ id, cities }` 更新一条 |
| POST | `/api/city-recipes/export-import` | 跑 import-recipes 或写 for-import |
