---

## 1. 目标

1. 结合点评 `tools/dianping-automator/output` 与可查常识，为 builtin 菜谱补 `cuisineTags`。  
2. 提供与忌口 / 城菜 / 难度同级的网页编辑入口，支持人审与多标。  
3. 明确「通用」语义及推荐时的生效规则。

---

## 2. 数据模型

| 项 | 约定 |
|----|------|
| 字段 | `cuisineTags: string[]`，可多值，**可空** |
| 通用 | code 仍为 **`home_style`**；编辑器展示名 **「通用」**；**不进**用户偏好词表 |
| 地方系 | 沿用 19 code：`sichuan` / `cantonese` / …（见 2026-10-12 词表） |
| 点评「火锅」「烧烤」 | **不写入** `cuisineTags`（形态仍属 `dishForms`；本期不自动改 `dishForms`） |
| 迁移 | 实现时**先清空** builtin 中现有的 `home_style`（仅含它则变为 `[]`）；其它已有地方系可保留，随后被自动打标覆盖/合并策略见 §3 |

---

## 3. 自动打标

脚本（可重跑，建议放 `scripts/` 或 `tools/alias-editor/` 旁，实现计划定路径）：

**顺序**

1. 清空策略：去掉全部现有 `home_style`；再按下列来源重写/合并地方系。  
2. 点评精确匹配：扫 `output/{城}/{菜系}/` 店菜与汇总 JSON，菜名归一化后与 builtin `name` 精确相等 → 加上对应英文 code。  
3. 相似匹配：归一化（去括号、份量、空白等）后，包含关系或编辑距离达阈值 → 命中该系。  
4. 仍无命中：用菜名关键词 / 公开常识弱规则补标；**无把握则保持空数组**。  
5. 多系命中 → **多标**。不确定不标「通用」；「通用」主要靠人在编辑器点选（自动规则仅在有强依据时才写 `home_style`）。

**报告**（可选文件）：精确 / 相似 / 规则 / 未标 计数与样例，便于人审。

**不自动做**：把点评火锅/烧烤映射进 `cuisineTags`。

---

## 4. 推荐：生效菜系

对每道菜计算 `effectiveCuisineTags`：

- 若 `cuisineTags` **包含** `home_style` → 生效集 = **空**（当通用：不因地方系 avoid 被踢，也不吃地方系 prefer）。同行其它地方系**在推荐里忽略**（数据可仍存在，便于编辑展示）。  
- 否则 → 生效集 = `cuisineTags` 中的地方系（不含 `home_style`）。  
- 标签为空 → 与「无菜系信息」相同：不因菜系硬排除 / 不加菜系 prefer。

硬排除 / 软加权仍只作用在**生效集**上（规则骨架同 2026-10-12）。

## 5. 编辑页（方案 C + 右键加标）

位置：`tools/alias-editor` 新 Tab「菜系」。

### 5.1 导航

左栏（带数量）：

1. **未标注**（默认）— `cuisineTags` 为空或缺失  
2. **通用** — 含 `home_style`  
3. 19 个地方系 — 含该 code（一道菜可出现在多个系栏）

### 5.2 列表

- 当前栏下的菜：拼音序 + **列优先**布局（同难度页）。  
- 每张卡：**菜名 + 主料**；右侧展示「**除当前导航系以外**」的已选标签芯片（如在「川菜」栏看某菜，右侧只显示它额外的粤菜/通用等，不重复显示川菜）。  
- 在「未标注」栏：右侧展示其全部已有标签（通常为空）。  
- 在「通用」栏：右侧展示除 `home_style` 外的地方系芯片。

### 5.3 交互

| 操作 | 行为 |
|------|------|
| **右键**卡片 | 在指针旁弹出**紧凑弹层**（约 **4×5 网格**）：「通用」+ 19 地方系共 20 格；**已选中的高亮**，未选普通样式；再点已选 → **取消**该系；点未选 → **加入**该系（均进草稿）。含「移出当前导航系」的能力（当前系若已选则高亮，再点即可取消） |
| **左键点击**右侧芯片 | **取消**该系归属（与弹层取消同一草稿逻辑） |
| 确认修改 | 将草稿写回 `recipes-builtin.json`（同难度：未保存切栏弹窗） |
| 导出 for-import | 复用现有 recipes for-import 导出（无未保存草稿时） |

卡片本体不平铺 19 系；选择只在右键弹层里完成，弹层小范围、可一眼扫完。

### 5.4 草稿与保存

- 与难度 Tab 相同：切导航 / 切 Tab 时若有草稿 → 保存 / 放弃 / 取消。  
- 保存后刷新分桶计数。

## 7. 验收

1. builtin 中原「仅 home_style」菜在跑自动脚本后可为 `[]` 或被补上地方系；不再依赖「全家 home_style」占位。  
2. 点评高频菜名能落到对应系；明显无把握的菜保持未标注。  
3. 编辑器：未标注队列可右键加系；右侧芯片可点掉；含 `home_style` 的菜在推荐逻辑上按通用处理（单测覆盖生效集）。  
4. 导出 for-import 后字段与 builtin 一致。
