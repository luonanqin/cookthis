# 同方案内去重（菜名 / 近义 / 主料集合）

日期：2026-10-09  
状态：已定稿（需求写入 `需求概述`；细则 → 推荐与反馈 **§3.0.7**）  
范围：家常 `planKind: home` 单套组菜；不改 §3.0.6 多方案之间上限。

## 背景

- 只按 `recipeId` 去重时，city pack 同名不同 id（如多个「辣子鸡」）会同套出现两次。  
- 同桶连取且未同步记账 / 过早放宽「主料不重复」时，「土豆烧牛肉」与「土豆炖牛肉」等会挤在一桌。  
- 多方案之间已有重复上限（§3.0.6）；**同一套内部**此前无菜名唯一与主料签名硬约束。

## 决策

- 主料撞车口径：**集合完全相同**才互斥（选项 A）；调味不参与。  
- 过滤顺序：**方案 1** — `recipeId` → 归一化菜名 → 主料集合全同 → 近义菜名（烹法词剥离）→ 软避开已用主料；仅最后一步可放宽。

## 非目标

- 不用 Jaccard / 核心主料子集（易误伤仅共用土豆等）。  
- MVP 不做土豆/马铃薯等完整别名词表。  
- 非常规火锅涮菜不套用「主料集合硬去重」（多道涮品本就多样）；仍避同名/`recipeId`。
