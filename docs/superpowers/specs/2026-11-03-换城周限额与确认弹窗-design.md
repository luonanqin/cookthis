# 换城周限额与确认弹窗

日期：2026-11-03  
状态：已拍板落地

## 规则

- 真实换城（账号已有城市 → 改为另一城）：自然周最多 **2 次**，**无间隔**。
- 周界：中国时区（UTC+8）周一 00:00 起算。
- 首次设城、同城再写：不计次、不拦截。
- 超额：云函数返回 `CITY_CHANGE_WEEKLY_LIMIT`。

## 客户端

- 仅「我的」偏好页：已有城市时 picker 选中不同城 → 确认弹窗。
  - 确定：保留新城（仍需点保存才写库）。
  - 取消：退回原城。
- 首次选城不弹；引导 / 轻量补全首次补城不弹。

## 实现要点

- 纯函数：`checkCityChange` 改为按 `cityChangeWeek` + `cityChangeCount` 计周额度。
- 计数写入 `users.accessGuard`；vendor 同步到 `profile`。
