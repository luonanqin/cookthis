# 字号 / 字重角色表

**日期**：2026-11-11  
**实现**：`miniprogram/app.wxss` 令牌 + 各页对齐  
**盘点**：Cursor canvas `typography-audit`

## 令牌

| 字号 | 普通 | 大字 |
|------|------|------|
| `--fs-xxs` … `--fs-page-title` / `--fs-brand` | 既有 | 既有 |
| `--fs-header` | 44rpx | 52rpx |

| 字重 | 值 |
|------|-----|
| `--fw-regular` | 400 |
| `--fw-medium` | 500 |
| `--fw-semibold` | 600 |
| `--fw-bold` | 700 |

## 角色绑定

| 角色 | 字号 | 字重 | 例子 |
|------|------|------|------|
| 页头标题 | `--fs-header` | `--fw-bold` | 「开始设置」 |
| 区块标题 | `--fs-title` | `--fw-semibold` | 「家庭忌口」「时令」 |
| 字段标签 | `--fs-md` | regular（可省略） | 「称呼」 |
| 正文 / 输入 | `--fs-body` | regular | 输入框、清单行 |
| 列表成员名 | `--fs-body` | `--fw-semibold` | 卡上「我」 |
| Chip / 旁注 | `--fs-sm` / caption | regular | 「无忌口」 |
| 主 CTA | `--fs-title` | `--fw-semibold` | 「下一步」「保存」 |
| 次按钮 | `--fs-btn` | `--fw-medium` | 「跳过」「上一步」 |
| 角标 | `--fs-xxs` | `--fw-semibold` | 首页缺口数字 |

`--fw-bold` 优先留给页头（及首页大字开关 glyph）；方案菜名等强调用 semibold，不再用 700。
