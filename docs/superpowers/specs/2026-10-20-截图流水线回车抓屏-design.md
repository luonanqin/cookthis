# 截图流水线：终端回车抓屏

状态：已定稿  
日期：2026-10-20

## 目标

在 `run_screenshot_pipeline.py` 监听中，人在手机上滑到合适位置后，在电脑终端按一次空回车，脚本用 adb 抓当前屏幕，并走现有「裁剪 → OCR → 追加 products.jsonl」流程，不必再按手机截屏键。

## 已定决策

| 项 | 决定 |
|----|------|
| 触发 | 终端**空回车**（空命令）= 抓屏 |
| 抓屏方式 | `adb exec-out screencap -p`，直接写本机文件 |
| 落盘路径 | `screenshots_inbox/{城}/{类}/enter_YYYYMMDD_HHMMSS.png` |
| 后续处理 | 与手机截屏拉回相同：`handle_new_local`（裁剪 + OCR） |
| 手机截屏监听 | **保留**，两种来源并存 |
| 其它命令 | `t/c/s/q/?` 不变 |
| 失败 | 打印错误，不退出监听 |

## 交互

监听提示改为：`回车=截图  t=切换类别  c=切换城市  s=状态  ?=帮助  q=退出`。

流程：

1. 人选好城市/类别，打开美团菜场列表，手动滑动
2. 终端回车 → 抓屏 → 裁剪 OCR → 追加汇总
3. 继续滑动，再回车；换类/换城仍用原命令

## 实现要点

1. `watch_screenshots.py` 增加 `capture_screen(out_path: Path) -> Path | None`  
   - 用**二进制**跑 `adb -s UDID exec-out screencap -p`（现有 `adb()` 是 `text=True`，不能直接复用写 PNG）  
   - 校验写出文件非空；失败返回 `None` 并打印 stderr
2. `run_screenshot_pipeline.py` 主循环：`cmd == ""` 时调用抓屏并 `handle_new_local`；非空命令逻辑不变
3. 更新该脚本顶部说明与 `README.md` 半自动截图一节一句说明即可

## 非目标

- 不自动滑动、不自动切类
- 不引入 Appium
- 不改 OCR 区域与清洗链路
