# 购物清单别名展示与推荐别名匹配

状态：已实现（见 `docs/superpowers/plans/2026-10-20-购物清单别名展示与推荐别名匹配.md`）  

日期：2026-10-20

## 目标

1. **推荐匹配**：用户确认的食材名可能是通用名或别名；菜谱主料也可能是另一叫法。经别名等价展开后，确认「鸡脚」应能命中主料为「鸡爪」的《红烧鸡爪》。
2. **购物清单展示**（去买菜后）：按用户所在城市展示当地叫法为主名，同行小字跟 1 个对照名；无城市则主名用通用名。

二者共用 `data/catalog/aliases.json` 与同一套等价语义；展示不改变匹配键。

## 已定决策

| 项 | 决定 |
|----|------|
| 清单版式 | **同行**：主名 + 灰色小字副名（方案 1）；有无副名都单行，避免两行导致网格错落 |
| 副名数量 | 至多 **1** 个；放不下先截/隐去副名，再截主名 |
| 有城、货架未命中该等价组 | 主名退回 **通用名**（同无城市） |
| 同组多名出现在该城货架 | 优先取 **≠ 通用名** 的当地名；多个再按货架稳定顺序取第一个 |
| 展示范围 | **仅**购物清单页两列勾选格；不含「看菜谱」弹层、方案卡 tip |
| 勾选持久化键 | **通用名**（无别名表则用原始名）；换城展示变、勾选不丢 |
| 匹配方式 | 对确认名集合 **一次**等价展开 → `主料 ⊆ 展开集`；禁止按每个别名反复搜库 |
| 别名主数据形态 | 保持 `aliases.json`：`通用名 → 别名[]`；运行时派生 `表面名 → 等价集` |
| 与城货架筛菜 | 语义同 `2026-10-18` 的「一次展开」；本设计先落地 **确认食材 → 候选**（修 `isCandidate`）；按城货架截断候选若未实现可随后对齐同一索引 |

## 背景与现状

确认页提交 `selectedIngredients[].name` → 推荐云函数 `selectedNames` → 家常候选：

```text
mains.every((name) => selected.has(name))  // 字符串精确相等
```

因此确认「鸡脚」、菜谱写「鸡爪」时当前 **不会**入选。  
`2026-10-18-城市货架与全量食材别名` 已约定别名表与一次展开语义，并提供工具侧 `alias_match.py`；**推荐云函数尚未接入**。购物清单目前直接展示菜谱字符串，无按城 remap。

## 别名索引（不改源文件结构）

### 源数据

`data/catalog/aliases.json`：

```json
{
  "鸡爪": ["鸡脚", "凤爪"],
  "番茄": ["西红柿"]
}
```

- 键 = **通用名**；值 = 别名列表（可不含键自身）。
- `_meta` 等以下划线开头的键不参与匹配。

### 运行时派生（加载一次，可实例缓存）

对每一组 `{canonical, ...aliases}`，为组内 **每个表面名** 写入同一 `Set`：

```text
鸡爪 → {鸡爪, 鸡脚, 凤爪}
鸡脚 → {鸡爪, 鸡脚, 凤爪}
凤爪 → {鸡爪, 鸡脚, 凤爪}
```

查任意确认名：`equiv.get(name) ?? {name}`，O(1)。  
当前表规模（百组 / 千级表面名）适合云函数与小程序内存；若未来极大，可改为预计算索引文件或入库，**源 JSON 形态与匹配语义不变**。

另需能取 **通用名**：`canonicalOf(surface)`（建索引时一并记下 `surface → canonical`；未入表则 `surface` 自身为 canonical）。

## 一、推荐：确认食材别名匹配

### 规则

1. `selectedNames` = 当次确认快照中的 `name` 列表（保持入库原样，不强制改成通用名）。
2. `selectedExpanded = ⋃_{n ∈ selectedNames} equiv(n)`。
3. 家常（及一切使用「主料 ⊆ 已选」的路径）改为：

   `recipe.mainIngredients` 每个名 ∈ `selectedExpanded`  
   （空主料等原有硬规则不变。）

4. 忌口、新鲜度、主料签名去重等：继续用菜谱上的 **字面主料名** 查食材元数据；查表前可用 `canonicalOf` 归一再查，避免「鸡脚」无文档、「鸡爪」有文档。实现时：**lookup 优先字面，未命中再试 canonical**（或统一 canonical），同一推荐请求内行为一致即可。

### 示例

| 确认 | 菜谱主料 | 结果 |
|------|----------|------|
| 鸡脚 | [鸡爪] | 命中（展开含鸡爪） |
| 鸡爪 | [鸡脚] | 命中（若菜谱误写别名） |
| 鸡脚 | [鸡爪, 土豆] | 仅当展开集也含土豆（或其别名） |
| 未入表「孜然」 | [孜然] | 命中（单点集合） |

### 非目标（匹配）

- 不按别名多次查询菜谱库。
- 不在本设计改菜谱入库文案；写菜谱仍循 2026-10-18（优先菜名内叫法，否则通用名）。
- 父子部位（猪肉 / 五花）仍非别名，不走本表。

## 二、购物清单：按城展示

### 范围

仅 `pages/shopping` 两列勾选列表。菜谱弹层、方案 tip 后置。

### 版式

```text
☑ 鸡脚 鸡爪
☑ 土豆
```

- 主名：常规字号、深色。
- 副名：同基线、更小更淡；与主名之间半角空格或间隔点 `·`。
- 整格 **单行**；溢出：先去掉副名，主名 `…` 截断。
- 无副名：只渲染主名，不留灰字占位。

### 取名算法

输入：清单条目的原始名 `raw`（来自方案 `mainIngredients` / `seasonings`）、`users.city`（可空）、该城货架名集合 `shelf`（可空）、`equiv` / `canonicalOf`。

1. 令 `canon = canonicalOf(raw)`，`group = equiv(raw)`。
2. **主名 `displayName`**
   - 无城市或 `shelf` 不可用：`displayName = canon`。
   - 有城市：`hits = group ∩ shelf`。
     - `hits` 空：`displayName = canon`。
     - 否则：在 `hits` 中优先选 `≠ canon` 的名；多个按货架遍历稳定顺序取第一个；若只有 `canon` 则主名=`canon`。
3. **副名 `secondaryName`（0 或 1 个）**
   - 若 `displayName ≠ canon`：`secondaryName = canon`。
   - 若 `displayName === canon`：取 `aliases.json` 中该键别名列表的 **第一项**（且 ≠ displayName）；列表空则无副名。
   - `raw` 未入别名表：无副名，`displayName = raw`。
4. **勾选键 `checkKey`**：始终为 `canon`（未入表则为 `raw`）。列表去重、本地 `cookthis_shopping_checks` 均用 `checkKey`，不用 `displayName`。

### 城市键

`users.city`（如 `重庆市`）与目录 `cities/{城}/` 对齐时去掉末尾「市」「省」「自治区」「特别行政区」等常见后缀；对不上则视为无货架，走通用名主名。

### 数据从哪来（展示）

推荐：**客户端渲染前 remap**（或云函数返回清单时带好 `displayName` / `secondaryName` / `checkKey`，换城需重算）。

- 小程序（或云端）持有别名索引；按 `city` 懒加载该城货架名集合（来自 `data/catalog/cities/{城}/ingredients.json` 的发布/导入产物，不必每次读仓库文件）。
- 聚合逻辑可继续用原始名；绑定到 UI 的 cell 使用上述三字段。

## 成功标准

- 确认「鸡脚」能推荐出主料含「鸡爪」的菜；确认「鸡爪」同样覆盖「鸡脚」写法。
- 匹配为一次展开 + 集合包含，非按别名多次搜库。
- 重庆用户清单上可见「鸡脚」为主名、「鸡爪」为副名（当货架有鸡脚时）；无城市时主名「鸡爪」，副名可为别名列表首项「鸡脚」。
- 两列网格行高一致；仅有主名的格子不因缺副名错位。
- 换城只改展示文案，已勾选状态按 `checkKey` 保留。

## 实现提示（非规范强制）

- 云函数：实例缓存 `buildEquivalence(aliases)`；在 `isCandidate`（及非常规里同类 ⊆ 判断）使用 `selectedExpanded`。
- 小程序：`utils` 内 `resolveShoppingLabel(raw, { city, shelf, equiv })`；shopping 的 `cell` 增加 `displayName` / `secondaryName`，`wx:key` / checks 用 `checkKey`。
- 测试：鸡脚↔鸡爪命中；无城展示；货架多命中优先异名；未入表名透传；checks 换城不丢。
