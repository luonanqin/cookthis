# 时令食材收起与抽屉 Design

> 日期：2026-11-19  
> 状态：待实现  
> 范围：确认食材页时令区块默认收起预览 + 抽屉点选；四季常见计数展示补全  
> 页面：`miniprogram/pages/confirm/*`

## 1. Goal

确认食材页默认更短：时令不以整表占屏，而是约一行半预览；完整分组点选放进抽屉。收起预览不反映选中高亮，但顶栏展示已选/全量。四季常见折叠条同时展示已选与全量。

## 2. Non-goals

- 不改四季常见的展开/收起交互（仍为页内 fold，非抽屉）
- 不改云函数、菜场规模档位、补菜/场景逻辑
- 不改默认勾选规则（时令默认全选、四季常见仍按忌口排除）
- 不做预览区按选中过滤或重排

## 3. UX

### 3.1 时令卡片（默认收起）

- 顶栏左侧：`时令` + 文案 `已选 x / 共 y`（`x` = 已勾选数，`y` = 时令列表总数）
- 顶栏右侧：保持「菜场规模 · 切换」入口不变
- 预览区：按现有类别顺序展平食材名；**无**类别标题、**无**芯片外框、**无**选中高亮（`chip-on`）
- 高度约 **1.5 行**；多出的半行用底部模糊/渐隐遮罩表现「还有更多」
- 点击预览区任意位置（含食材名）→ 打开时令抽屉；**不**切换该食材选中态
- 收起卡片上 **不展示** 全选 / 清空

### 3.2 时令抽屉

- 内容与改版前页内时令一致：按类别分组 + 带框芯片 + 选中高亮
- 抽屉内保留全选 / 清空；点芯片仍即时切换选中
- 底部「完成」按钮关闭抽屉；点遮罩也可关闭
- 关闭不清空已选；选中变化只刷新计数与抽屉内芯片，**不**改变收起预览的视觉样式

### 3.3 四季常见

- 折叠条文案改为同时展示已选与全量，例如：`四季常见 · 已选 x / 共 y`
- 展开/收起、分组芯片点选逻辑不变

## 4. 状态与数据

| 字段 | 作用 |
|------|------|
| `seasonalDrawerOpen` | 控制时令抽屉显隐；纳入 `page-meta` 溢出锁定（与现有 sheet 同类） |
| `seasonalFlat` | 由 `seasonalGroups` 按类别顺序展平，供收起预览渲染 |
| `seasonalCount` / `seasonalTotal` | 已选 / 时令总数 |
| `yearRoundCount` / `yearRoundTotal` | 已选 / 四季常见总数 |

- `_counts`（或等价处）在现有 selected 计数上补充 total（对应列表长度）
- 开/关抽屉：`onOpenSeasonalDrawer` / `onCloseSeasonalDrawer`；完成与遮罩共用关闭
- 选中态仍存 `seasonalChecked`；预览 DOM 不绑定 `chip-on`

## 5. 实现边界

- 改动文件：`confirm.wxml` / `confirm.wxss` / `confirm.js`；可选新增页面级测试
- 复用现有 `mask` + `sheet`（`app.wxss` / 页内 sheet）模式
- 预览高度用 `max-height`（约 1.5 行，按现有字号/行高换算 rpx）+ 底部渐隐/模糊层；不依赖截断真实数据

## 6. 验收

- [ ] 进入确认页时令默认收起，约 1.5 行 + 半行模糊，无类别、无外框
- [ ] 点击预览任意食材只开抽屉，不改变该食材勾选
- [ ] 抽屉内分组/芯片/全选/清空与改版前一致；完成与遮罩可关
- [ ] 勾选变化后收起预览样式不变，顶栏 `已选 x / 共 y` 正确
- [ ] 四季常见折叠条同时显示已选与全量
- [ ] 菜场规模切换、补菜、去推荐等原流程不受影响
