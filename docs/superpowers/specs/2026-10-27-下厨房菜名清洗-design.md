# 下厨房结果菜名清洗

日期：2026-10-27  
状态：已定稿

## 目标

清洗 `data/recipes/xiachufang/xiachufang-{category,search}-results.json` 的 `recipes[].title`：去掉营销修饰，保留食材与做法；标题洗空则删除该 recipe。`ingredients` 不动。结构不变。提供可复跑脚本。

## 规则要点

- 去 emoji / 装饰标点；按 `——｜|` 等择菜名侧；引号内菜名优先。
- 删整段套话（「家常下饭菜」「教你做一道…」等），**不**单独删词「家常」「下饭」。
- 删口感修饰：鲜美、低脂、细嫩、Q弹、浓郁、爆汁等。
- **通用截尾**：定位食材锚点（条目名 → recipe.ingredients → 词表最长匹配）；锚点后缀不以做法词开头则整段删除。
- 去掉全部英文与标点（只留汉字/数字）；字数 < 3 → 删除。
- 清洗后 title 恰好等于 `ingredients-all.json` 中的食材名（或当前条目名）→ 删除该 recipe。
- 同一食材下按清洗后 title 去重（保留首次；ingredients 并集保序）。
- 输出：同结构 JSON；默认写清洗后文件（见脚本参数）。

## 脚本

`scripts/clean-xiachufang-recipe-titles.py`
