# 「我的」做饭水平内嵌

**日期**：2026-11-06  
**关联**：[`2026-11-05-做饭能力与菜品难度-design.md`](./2026-11-05-做饭能力与菜品难度-design.md)、[`2026-10-02-详细设计-用户画像.md`](./2026-10-02-详细设计-用户画像.md)

## 目标

「我的偏好」在**所在城市**与**菜系偏好**之间展示与引导同款 15 选，可回填；保存时校验至少勾 1 道。

## UI

| 项 | 约定 |
|----|------|
| 位置 | 城市 → **做饭水平** → 菜系 → 菜式 |
| 标题 | `做饭水平` |
| 旁注 | 右侧 `section-aside`：`选择会做或者没做过但觉得简单的`（与其它区块一致） |
| 告警 | 未勾选时用 `section-title-gap` 标红（同忌口/城市/菜系），不用单独 `title-warn` |
| 内容 | 三组 chip，交互同引导；不展示 beginner/home/skilled |
| 入口 | 去掉页内「测一下 / 已测」轻链；独立 `cookSkillProbe` 页可保留兼容 |

## 校验与写档

- 「保存」：至少勾 1 道，否则标题闪红、整页不保存（引导页仍可跳过）
- 有勾选：与其它偏好一并保存；写 `cookSkill`（服务端 derive）、`cookSkillProbeCounts`、`cookSkillProbeDishIds`、`cookSkillProbeAt`
- 零勾选不改已有档（被校验拦住，写档不走到空提交；也不预勾任何菜）
- 首页「我的」红点：`computeProfileGaps` 含 `cook_skill`（无 `cookSkillProbeDishIds` 即开），与忌口/城市同套计数

## 落库

| 字段 | 说明 |
|------|------|
| `cookSkillProbeDishIds` | `string[]`，勾中的探针菜 id（须落在当前 `PROBE_DISHES`） |
| `cookSkillProbeCounts` | 仍写，由勾选派生 |

引导 `completeOnboarding`、以及「我的」保存 / `saveCookSkillProbe` 均写 dishIds。`login` / 画像读回用于回填。仅有旧 counts、无 dishIds 时勾选为空，保存前须重选。
