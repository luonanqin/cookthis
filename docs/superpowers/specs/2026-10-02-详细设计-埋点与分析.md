## 1. 目标

- 全端统一事件名与属性，便于日后 App 共用  
- **全打**已放出能力；未放出入口（如拍照）不打占位失败事件  
- 支撑：进场完成率、换一批、采纳进清单、记录、回访等

## 2. 存储与上报

### 2.1 `events` 集合

| 字段 | 说明 |
|------|------|
| `uid` | 未登录可空 |
| `event` | 事件名 |
| `props` | object |
| `platform` | `mp` \| `ios` \| `android` |
| `loginProvider` | 可选：`wechat_mp` 等 |
| `appVersion` | 小程序版本 |
| `sessionId` | 会话 |
| `requestId` | 可选，推荐会话 |
| `ts` | 客户端时间 |
| `serverTs` | 服务端写入时间 |

### 2.1.1 完整示例（1 用户 : N 事件；可选挂 requestId）

关系：同一 `uid` / `sessionId` 下多条 `events`；推荐相关事件共用 `requestId`，与 `recommendations` 对齐。

### 2.2 客户端

- 统一 `track(event, props)`  
- 本地队列批量 → `analytics.trackBatch`（建议 10 条或 5s）  
- 失败重试；不阻塞主流程  
- **禁止**把 openid、完整手机号写入 props  

### 2.3 云函数 `analytics.trackBatch`

- 校验登录态（允许少量匿名 `app_open`）  
- 批量 insert；超限丢弃并打日志

### 3.5 推荐 / 清单

| event | props 要点 |
|-------|------------|
| `recommend_show` | `planCount`, `latencyMs`, `planKinds[]` |
| `recommend_plan_impression` | `planIndex`, `planKind` |
| `recommend_plan_click` | `planIndex` |
| `recommend_swap` | `swapIndex`，`dwellMs` |
| `recommend_reject` | `reason?`，`skippedReason`，`dwellMs` |
| `recommend_accept` | `planIndex`，`dwellMs` |
| `recommend_engage` | `planIndex`, `dwellMs`（≥30000，进场确认锚点） |
| `recommend_batch_dwell` | `dwellMs`，`endReason=leave`（卸载页且未 swap/reject/accept） |

**方案认可度（`dwellMs`）**：对「当前这一批方案」的**绝对停留时长**（前台可见累计 ms），不是均值、不是会话平均。换一批 / 不行后重新从 0 计；切后台只暂停、回前台继续累计。解读约定：同批内停留越长 → 用户越认可当前方案（越合适）；在 swap / reject / accept / leave 终点各打一次，便于对比「看了多久才换/否/采纳/离开」。
| `empty_recommend` | `reasonCode?`，`action?`（`create`/`swap`/`reject`）；配合「好吧」弹窗，非整页空态 |
| `shopping_list_open` | `accepted`（产品上仅「去买菜」进入，应为 `true`） |
| `shopping_list_item_check` | `name`, `checked` |
| `shopping_list_done` | `checkedCount` |
| `shopping_recipe_sheet_open` | `planIndex` |
| `shopping_recipe_sheet_close` | `planIndex`, `dwellMs`, `scrolled` |

## 4. 与验证指标映射

| 指标 | 算法思路 |
|------|----------|
| 进场完成 | `confirm_sheet_submit` / `market_entry` |
| 换一批 | `recommend_swap` 次数 / 有 `recommend_show` 的会话 |
| 采纳进清单 | `recommend_accept` 且随后 `shopping_list_open(accepted=true)` |
| 主动记录 | `meal_log_manual` + `meal_log_voice_result(success)` |
| 7 日回访 | 同一 uid 两日 `app_open`/`session_start` 间隔 |

报表可用云开发控制台导出或简易统计云函数；不做完整 BI。
