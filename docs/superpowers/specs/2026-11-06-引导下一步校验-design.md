# 引导「下一步」分步校验

**日期**：2026-11-06  
**范围**：`miniprogram/pages/onboarding`  
**关联**：[`2026-10-02-详细设计-用户画像.md`](./2026-10-02-详细设计-用户画像.md) §4.1；[`2026-11-05-做饭能力与菜品难度-design.md`](./2026-11-05-做饭能力与菜品难度-design.md)

## 目标

点「下一步 / 完成」时校验**当前步**是否已填写；失败则统一告警、不前进。「跳过」不校验（家庭成员步仍无跳过）。

## 规则

| 步骤 | 「下一步」 | 通过条件 |
|------|-----------|----------|
| 家庭成员 | 拦 | 每位成员：称呼非空、年龄段已选、个人忌口已表态（「无」或 ≥1） |
| 日常搭配 | 不拦 | 有默认值 |
| 家庭忌口 | 拦 | 「无」或 ≥1 项 |
| 所在城市 | 拦 | 已选城市 |
| 做饭水平 | 拦 | 至少勾 1 道探针菜 |
| 菜系偏好 | 拦 | 「都还行」或任一喜欢/不喜欢 |
| ~~菜式偏好~~ | — | **本期引导步已隐藏**；恢复后仍可不拦（默认无所谓） |

「跳过」：不校验本步；做饭水平跳过仍不写 `cookSkill`（与现有一致）。

## 告警 UI（统一）

与家庭成员步 / 确认页一致：

- 未填区块的**标题**（`section-title` 或成员字段 `form-label`）加 `title-warn` + `title-pulse` 闪缩约两下
- **不**另弹 `wx.showToast` 做缺填提示
- 用户补全对应项后清除标红

做饭水平未勾选时，对「做饭水平」标题闪红。

## 做饭水平语义变更

| 操作 | 旧 | 新 |
|------|----|----|
| 零勾选 +「下一步」 | 写入 `beginner` | **拦住**，须至少勾 1 道 |
| 「跳过」 | 不写 `cookSkill` | 不变 |

零勾选若要当新手：应至少勾一道「轻松上手」再点下一步，或改走「跳过」保持无档。

## 实现要点

- `onNext`：按 `step` 调 `_validateCurrentStep()`；失败 return；成功再前进 / `finish`
- `onSkip`：不走校验（现状保留）
- 非成员步复用与 `confirm` 同模式的 `warnXxx` + `_flashWarnTitles`；成员步沿用现有 `_flashWarn` / `warnFields`
- 忌口 / 城市 / 菜系 / 探针勾选变更时清对应 warn

## 非目标

- 不改「我的」编辑校验
- 不改轻量补全弹层
- 不改底栏布局
