# 菜场规模与食材列表档位

日期：2026-10-14  
状态：已定稿（**后置**；先做食材名单与排序，规模档再实装）  
相关：确认页时令/四季截断；与进场确认弹层的时序。

## 背景

- 餐厅主料 ≠ 菜场必有；美团卖菜货架往往宽于普通线下菜场。  
- 用「小 / 中 / 大」菜场规模调节：（1）确认页时令/四季**展示条数**；（2）大类勾选后的 **`implies` 隐含小类包**（只进推荐可用集，**确认页不展示小类**）。  
- 资格池排序仍按「城市 + 需求∩货架」；近距离中↔小靠页内改档。

## 决策摘要

| 项 | 结论 |
|----|------|
| 选项 | 小 / 中 / 大，均带说明文案；下方另有 **「默认中菜场」** |
| 「默认中菜场」 | **截断按中**，但落库 choice=`default_medium`，与用户点「中菜场」的 `medium` **可区分** |
| 默认（从未选） | **中** |
| 首次出现 | 进确认页**之前**弹层（见时序）；**仅当能拿到定位时**弹；拿不到则不弹、默认中 |
| 记住 | 写 **账号**（`users`）；换机仍在 |
| 再弹 | **须拿到定位**，且距上次规模弹窗/选档 **≥ 30 分钟**，且相对锚点位移 **≥ 约 1 km**；拿不到定位 → **不弹**，沿用最近一次档位（从未选过则默认中） |
| 同片区换中↔小 | **不**靠定位；确认页提供改规模入口；**切换成功后时令 + 四季均须按新档刷新** |
| 时令主列表条数 | 小 **10** / 中 **20** / 大 **30**（后续可调） |
| 四季常见条数 | 小 **12** / 中 **18** / 大 **24**（初值，后续可调；仍折叠不占主列表） |
| MVP | **后置**（本期先定名单与排序；规模 UI 与截断接档后做） |

## 与进场确认是否冲突？

**会抢注意力，但可用时序避免「两层同时弹」。**

进入「今天菜场有什么」时约定：

```
首页点击
  → 若需进场确认：只弹进场确认（已吃）
  → 关闭后（确认/跳过）或无需进场确认
  → 若需选菜场规模：再弹规模（小/中/大/默认中菜场）
  → 再进入确认页（食材+场景）
```

规则：

- **禁止**进场确认与规模选择叠在同一屏。  
- 规模已记住且未触发「走远了」→ 进场确认后（或无需确认时）**直接进确认页**。  
- **拿不到定位（拒权 / 失败 / 超时）→ 不弹规模窗**，沿用账号最近一次 `marketScale`；若从未选过则按默认 **中** 进确认页（可用页内「切换」改）。  
- **距上次选档 / 规模弹层处理未满 30 分钟 → 不弹**，沿用最近一次档位（半小时内跨很大菜场的概率低）。  
- 同一小程序会话内规模弹层最多一次（避免进场确认→食材之间 GPS 抖一下再弹）。

## 选项文案（露出说明）

- **小菜场** — 小门面、路边摊位  
- **中菜场** — 小超市、连着几个门面  
- **大菜场** — 集贸市场、大超市、很多摊位  
- **默认中菜场** — 按中菜场档位展示（可之后再改）

## 数据（实装时）

```ts
type MarketScaleChoice = "small" | "medium" | "large" | "default_medium"
// small/medium/large = 用户点了对应档；default_medium = 点了「默认中菜场」（截断同 medium，分析可区分）

type MarketScaleHistoryItem = {
  choice: MarketScaleChoice
  effective: "small" | "medium" | "large"  // default_medium → medium
  source: "sheet" | "page_switch" | "system_default"  // 弹层 / 确认页切换 / 无定位未选过时的系统默认
  lat?: number
  lng?: number
  at: string  // ISO 时间
}

// users（示意）— 最新快照 + 历史
marketScaleChoice?: MarketScaleChoice           // 最近一次选择（可区分默认中）
marketScaleEffective?: "small" | "medium" | "large"  // 截断用；由 choice 派生
marketScaleAnchor?: { lat: number, lng: number }     // 最近一次有定位时的锚点
marketScaleChosenAt?: string                    // 最近一次选档时间；30 分钟冷淡期
marketScaleHistory?: MarketScaleHistoryItem[]   // 历史，按 at 追加；建议最多保留最近 30 条（超出丢最旧）
```

派生：`effective = choice === "default_medium" ? "medium" : choice`。  
系统在「无定位且从未选过」静默用中时：写入 `choice=default_medium`、`source=system_default`，并追加一条 history（可选；若不想污染历史可只写快照不入 history——**建议仍入 history** 便于统计「有多少人从未点过」）。

确认页改档：更新上述快照字段 + **追加一条** `marketScaleHistory`（不要只覆盖导致丢历史）；有定位则更新锚点。**切换成功后必须同时刷新**：
- **时令主列表**（`seasonal`）：按新档 `effective` 条数重截、重渲染；  
- **四季常见**（`yearRound`）：按新档重截，折叠区与勾选一并更新。  

已勾选项：与新列表交集的尽量保留勾选；落出新列表的去掉；新进列表的按时令默认全选 / 四季默认计入规则处理。

## 截断规则

1. 候选池：按城过滤后的 ingredients（资格：排序分，餐厅需求 ∩ 美团货架等，见食材筛选讨论；本设计不定义打分公式）。  
2. 分成 `yearRound` / `seasonal`。  
3. 按档截断到上表条数（`sort` / 分数从高到低）。  
4. 主列表只渲染 seasonal；yearRound 折叠默认计入。

## 定位再问

须**同时**满足才弹「走远了」类规模窗：

1. 成功拿到当前定位；  
2. 与 `marketScaleAnchor` 直线距离 **≥ 约 1 km**；  
3. 距 `marketScaleChosenAt`（上次选档或弹层关闭）已满 **30 分钟**。

否则 **不弹**，保持最近一次档位：

- **拿不到定位** → 不弹；  
- **半小时内** → 不弹（即便位移 ≥1 km，也认为同一次买菜行程）；  
- 无历史档位 → 默认中。  

不用 500 m（易误弹）。  
用户仍可在确认页主动「切换」改档（成功则更新 choice/effective/时间/锚点并 **append history**；无定位则 lat/lng 可空）。  
页内主动切换**不受** 30 分钟限制。

UI 展示当前档：`medium` 显示「中菜场」；`default_medium` 显示「默认中菜场」（或「中菜场（默认）」），避免和真选中混淆。

## 确认页改档入口

轻文案如「中菜场 · 切换」或「货架不对？切换菜场规模」→ 同款三档 + 「默认中菜场」。  

**切换成功后**：按 `effective` 立即重截并刷新 **时令 + 四季**；写回快照 + 追加历史。选「默认中菜场」时 `choice=default_medium`、`effective=medium`，**不要**写成 `choice=medium`。

## 展示集 vs 可用集（大类 / 小类）

| 集合 | 用户是否看见 | 作用 |
|------|--------------|------|
| **展示集** | 是（时令/四季/手补） | 确认页勾选；**各档都不铺小类**（不因大菜场就列出五花/排骨等） |
| **可用集** | 否（手补除外） | 推荐判够料；= 已勾展示项按当前规模展开的 `implies` ∪ 手补 id |

规则：

- 同义（番茄/西红柿）→ 一个 canonical；父子（猪肉/五花）→ 分 id + `implies`，**不**合成一个 id。  
- 菜谱要五花：仅当五花 ∈ 可用集才可出；清单仍写「五花肉」。  
- 用户可手补小类；不补则严格按该档 `implies` 定义。

### 猪肉 `implies` 初稿（可调）

展示项固定为 **「猪肉」**（`pork`）。按 `effective` 规模展开：

| 规模 | `pork` 隐含可用（展示名） |
|------|---------------------------|
| **小** | 猪肉、前腿肉、后腿肉、瘦肉、肉馅/绞肉 |
| **中** | 小档全部 + 五花肉、排骨（肋排）、龙骨、蹄膀 |
| **大** | 中档全部 + 梅花肉、里脊、寸排、猪肚、猪肝、猪血、猪皮 |

说明：

- 小档**不含五花/排骨**：避免默认推出红烧肉/排骨汤却小摊不好买；要吃可手补。  
- 中档补上家常高频部位。  
- 大档再加内脏与更细部位（集贸常见）。  
- 「猪肉」本身始终在包内，菜谱只写「猪肉」也能匹配。  
- 其它大类（牛/羊/鸡/鱼…）同结构另表；本设计先定猪肉样板。
