# 需求摘要：方案分享

状态：需求已记录；设计已定稿；**已实现**（2026-10-28）→ `2026-10-28-方案分享-design.md`  
日期：2026-10-24（设计 2026-10-28）  
权威正文：`doc/需求概述.md` 模块 3「方案分享」

## 为什么做

- 去菜场的人不一定是做饭的人；买菜方确认「能买到 + 能做」后，需要把方案甩给做饭的人照着买/做。
- 被分享者下次也能打开小程序用，形成传播。

## 已定（含设计拍板）

| 项 | 决定 |
|----|------|
| 入口 | 推荐页**每张方案卡**；购买食材页；「我的 → 已选方案」**自产**条目 |
| 形态 | 点对点；云端**只读快照** + `shareId`；不是社区 / 排行榜 |
| 打开 | 只读预览（菜名+完整用料）→「保存到我的」；预览不强制登录 |
| 回访 | 并入「已选方案」+「分享」标签；点开同款只读；收到的**不可再分享** |
| 不做 | 步骤、已买勾选、去买菜/已吃（收到的）、二次更新快照 |

## 非目标（本项）

- 公开 Feed、点赞、排行榜
- 语音 / 拍照相关入口
