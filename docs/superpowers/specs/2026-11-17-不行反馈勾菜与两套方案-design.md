# 不行反馈勾菜与两套方案

**日期：** 2026-11-17  
**状态：** 待实现  
**相关：** `pages/recommend`、「不行」面板、`buildHomePlans`、`2026-10-02-详细设计-推荐与反馈.md` §3.2 / §3.0.6

## 问题

1. 「不行」只选一个全局原因，无法标出具体哪几道菜、也不能一菜多原因。  
2. 同屏三套方案需要滑屏才能看完，对比负担大。

## 目标

- 「不行」改为：**原因选项卡 + 勾菜**；一道菜可挂多个原因；无面板大标题。  
- 可选菜 **≤10**，从当前批方案按荤/素/汤比例抽样，并用小标签区分。  
- 家常推荐目标套数 **3 → 2**。  
- 本设计以**交互与展示**为主；降权/写库细则可沿用现 reject 管道，勾选结果先随请求带上即可（字段见下），不做「只换问题菜」算法。

## 1. 「不行」面板交互

### 1.1 结构

| 区域 | 内容 |
|------|------|
| 标题 | **去掉**「不太合适的原因（可选）」 |
| 顶栏 | 4 个原因选项卡：不想吃 / 食材不对 / 太麻烦 / 最近吃过；进入默认选中「不想吃」 |
| 列表 | ≤10 道候选菜；左侧/旁侧 **荤·素·汤** 小标签（复用推荐页 `type-badge` / `MEAT_VEG_LABELS`） |
| 菜名旁 | 已挂原因的小标签（可多枚） |
| 底栏 | **跳过**（不标菜直接换批）· **完成**（提交当前勾选映射后换批）· **取消**（关面板，不换批） |

- 点菜：在**当前原因**下勾选/取消；换原因再勾其他或同一道菜。  
- **一菜多原因**：在原因 B 下勾同一道菜时**保留**原因 A。  
- **完成**在零勾选时等价于跳过（减少纠结）。  
- 点遮罩 = 取消（与现行为一致：不记 reject、不换批）。

### 1.2 候选菜池（≤10）

1. 从**当前这批** `plans` 展平菜品，按 `recipeId` 去重（无 id 则用规范化菜名）。  
2. 按 `meatVeg` 分成 `meat` / `veg` / `soup`；其它类型**不进池**（非常规涮品等本批若无荤素汤则池可为空 → 仅原因可选或直接跳过换批，产品上允许空列表 + 跳过/完成）。  
3. 上限 **10**：按三类在去重全集中的**数量比例**分配名额；某类为 0 则名额匀给有菜的类；用最大余数法保证整数且总和 ≤10。  
4. 同类内按出现顺序（方案下标升序、顿次、菜序）取满名额；全集不足 10 则全展示。  
5. 列表展示顺序建议：荤块 → 素块 → 汤块（块内保持抽样顺序），便于扫读。

### 1.3 客户端状态（示意）

```text
activeReasonId: 'dont_want' | ...
dishReasons: { [recipeKey]: Set<reasonId> }  // 一菜多原因
rejectDishPool: { recipeId?, name, meatVeg, reasonIds[] }[]
```

完成/跳过时组装 payload（供现有 `_rerun('reject', …)` 扩展；本阶段不强制服务端消费细节）：

```text
{
  reason?: string,           // 可选：主原因或省略
  dishFeedback?: { recipeId?, name, reasons: string[] }[],
  skippedReason?: boolean    // 跳过或零勾选
}
```

## 2. 推荐两套方案

- `buildHomePlans` 默认 `maxPlans`：**3 → 2**（`_shared` + `recommend` vendor 同步）。  
- `create` / `swap` / `reject` 重跑凡未显式传 `maxPlans` 的，均出最多 2 套家常。  
- §3.0.6 方案间重复：只约束两套两两比较（不再有第三套）。  
- 测试与文案中写死「3 套 / target: 3」的改为 2；`recipePool` 默认 target 若仍为 3，与家常 `maxPlans` 对齐检查，避免「池认为还要凑 3」与「只出 2」不一致。  
- 非常规方案插入逻辑保持现规则；家常基数变为 2。

## 3. 非目标

- 不按勾选「只替换问题菜、保留其余」。  
- 不改「去买菜」/换一批主路径（换一批仍可不经本面板）。  
- 不恢复面板大标题。

## 4. 验收要点

- 不行面板无大标题；原因选项卡 + ≤10 菜；荤素汤小标签可见。  
- 同一道菜可挂多个原因标签；取消某一原因下的勾不影响其它原因。  
- 跳过 / 零勾选完成 → 换批；取消 → 不换批。  
- 新会话推荐首页常最多 2 套，首屏对比无需为第三套滑屏（视机型高度；两套为硬目标）。
