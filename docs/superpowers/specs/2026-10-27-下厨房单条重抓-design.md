# 下厨房扩展：单条食材重抓

日期：2026-10-27  
状态：已定稿  
相关：`tools/xiachufang-popularity-ext/`

## 目标

在 popup 内输入食材名即可重抓；完成后自动导出全套结果文件（同名 overwrite），只覆盖该食材在结果里的条目，保留其它 `xcfDone` 数据。跑完只这一条后暂停。

## 行为

1. 输入框 +「重抓此食材」；须停留在下厨房标签页。
2. 若 `xcfRun.status === running` → 拒绝并提示先暂停。
3. 名称必须在打包词表 `data/ingredients.json` 的 `items` 中。
4. 从 `xcfDone` 删除该键；`xcfProgress.searched` 同步去掉。
5. 设 `xcfRun.refetchOnly = name`，启动与「继续」相同的页面循环，但只处理这一项。
6. 该项写入 `xcfDone` 后：立即 `PERSIST`（`download: true`）→ 清除 `refetchOnly` → `status=paused`，`pauseReason=已重抓并导出「…」`。
7. 导出仍用全量 `xcfDone` 重建四份结果 + progress；同名覆盖下载目录文件。若结果类型变化（如 category→search），旧桶中该项自然消失。

## 非目标

- 不写磁盘仓库路径（仍靠浏览器下载目录覆盖）。
- 不批量重抓；不改整表采集节奏。
