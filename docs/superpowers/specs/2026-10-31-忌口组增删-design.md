# 忌口组增删（alias-editor）

状态：已实现（见 [`../plans/2026-10-31-忌口组增删.md`](../plans/2026-10-31-忌口组增删.md)）  
相关：[`2026-10-30-忌口avoidTags人工编辑-design.md`](./2026-10-30-忌口avoidTags人工编辑-design.md)；`tools/alias-editor`；`ingredients-major-minor.json` 的 `avoidVocab` / `avoidMembers`

## 目标

在忌口 Tab 中**增加 / 删除忌口组**，先维护好分组底稿。小程序「我的」偏好词表**暂不改动**。

## 决策摘要

| 项 | 选择 |
|----|------|
| 词表真源 | `ingredients-major-minor.json` 的 `avoidVocab`（方案 A） |
| 新增 | 只填中文 `label`，自动分配 `id = gN` |
| 删除 | 二次确认后整组删除（含 `avoidMembers` 该 key）；原六码亦可删 |
| 代码六码 | 仅作空文件种子；有稿后以文件为准 |
| 偏好页 | 不改 `mine.js` / 推荐过滤 |

## 1. 数据

不变结构：

```json
{
  "avoidVocab": [{ "id": "pork", "label": "猪肉类" }, { "id": "g1", "label": "羊肉" }],
  "avoidMembers": { "pork": ["五花肉"], "g1": [] }
}
```

- `ensure_avoid_fields`：仅当缺/空 vocab 时写入默认六码；**不得**在每次保存成员时把 vocab 打回硬编码六码。  
- 现有 `PUT /api/avoid` 若仍强制 `mm["avoidVocab"] = AVOID_VOCAB`，视为缺陷，本需求一并修掉。

### id 规则

- 新增：`g` + 正整数；取现有 id 中匹配 `^g(\d+)$` 的最大数字 +1；若无则 `g1`。  
- 不与 `pork` 等非 `gN` id 冲突。  
- 不引入拼音库；不做重命名 / 改 id / 排序（非目标）。

## 2. API

| 方法 | 路径 | 行为 |
|------|------|------|
| POST | `/api/avoid/vocab` | body `{ "label": "羊肉" }` → trim；非空；与现有 `label` 精确相等则 400 → 分配 `gN` → append vocab + `members[id]=[]` → 写盘 → 返回 `{ ok, id, avoidVocab, avoidMembers }` |
| DELETE | `/api/avoid/vocab?id=<id>` | 缺 id / 未知 id → 400/404；否则从 vocab 移除该项并从 members 删 key → 写盘 |
| PUT | `/api/avoid` | **只**更新 `avoidMembers`；key 必须 ⊆ 当前 vocab ids；**不改** `avoidVocab` |
| GET | `/api/avoid` | 照旧返回文件中的 vocab + members |
| POST | `/api/avoid/bootstrap` | force 时只重填 members（按**当前** vocab ids 收纳 builtin tags）；**不重置**自定义 vocab |
| POST | `/api/avoid/export` | 按当前 vocab ids 全量重算 builtin `avoidTags` |

校验与成员增删：`add_member` / `export` / `bootstrap` 使用**传入或文件中的** id 集合，不再写死 `AVOID_IDS`（默认种子常量可保留）。

## 3. UI（忌口 Tab）

- 组 chip 旁：**「+ 忌口组」** → `prompt` 中文名 → POST vocab → 选中新组并刷新。  
- 每个组 chip：**选中**仍为单击 label 区域；**「×」** → `confirm('删除「…」及其 N 个成员？')` → DELETE → 若删的是当前组，切到词表第一项（词表空则清空主区）。  
- 池点击加入 / 组点击移除（已有）保持不变。  
- 提示文案：可增删忌口组；偏好页词表暂不动。

## 4. 验收

1. 可新增组（仅 label），落盘 `gN` + 空成员，并可加人。  
2. 任一组（含原六码）可确认删除；刷新后仍无。  
3. 保存成员不再把词表打回硬编码六码。  
4. 导出按当前词表写入 builtin；新组 code 出现在对应 `avoidTags`。  
5. 「我的」忌口仍为原六项。
