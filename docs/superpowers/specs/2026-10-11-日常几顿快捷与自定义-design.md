# 日常几顿：快捷 + 自定义

日期：2026-10-11  
**修订：2026-11-19** — **暂不分午饭 / 晚饭**；快捷最多 **6** 顿；**自定义**需看广告或开会员后可选最多 **10** 顿。  
状态：**已按顿数实现**（快捷 1～5、「更多」6～10 门控最多 10；阶段 1 广告解锁未做，非会员自定义走开通会员门槛）。  
**实现计划：** [`../plans/2026-11-19-日常几顿只选顿数.md`](../plans/2026-11-19-日常几顿只选顿数.md)  
**实现分支：** `feat/daily-meal-count-2026-11-19`  
范围：确认页**日常**「几顿」；推荐页 / 已选方案展示；会员权益文案联动。聚会仍只调顿数。

## 背景

- 曾实现：日常快捷（一顿晚饭 / 一顿午饭 / 1午+1晚）+ 自定义午/晚步进；`mealSlots` 带 `meal: lunch | dinner`。  
- **现状结论**：推荐引擎对 lunch/dinner **无差异化出菜**（各顿共用同一 `combo`），午晚仅标签。  
- **现目标**：日常与聚会一样，**只选要做几顿**；展示用中性顿次名；自定义多顿作为会员/激励权益。

## 决策（2026-11-19）

| 项 | 结论 |
|----|------|
| 午 / 晚区分 | **暂不做**（产品与推荐均不依赖） |
| 日常快捷 | **1～5 餐**芯片 +「更多」**6～10**；**禁止**「一顿午饭」「n午+m晚」 |
| 自定义 | 点「自定义」→ **会员直接开**；非会员 **看激励广告或开通会员** 解锁后 → 单轴步进选 **1～10** 顿。**禁止**午/晚两个步进框 |
| 免费硬顶 | 非会员（且无当日广告解锁）日常 `mealSlots.length` **≤ 5**（服务端强制）；解锁后 **≤ 10** |
| 会员 / 已解锁 | 日常最多 **10** 顿 |
| 聚会 | 不变：默认 1 顿「本场」、可改顿数，`meal: "other"`（聚会上限仍按现网，不与日常 10 混用） |
| `mealSlots` | `{ meal: "other", label: "第1顿" \| "第2顿" … }`；**不再**写 `lunch`/`dinner` /「午饭①」「晚饭①」 |
| 各顿 combo | 仍共用当次一个 `combo` |
| 画像 `mealTimes` | **保留**（午饭/晚饭时刻），与当次几顿无关 |
| 饮食记录 | 手动记饮食仍可填午/晚；与确认页解耦 |
| 推荐 / 已选方案 | **不**再展示午晚饭标记；多顿用「第N顿」；场景摘要用「N顿」而非「一顿晚饭」 |
| 会员权益 | 增加「日常多顿（自定义最多 10 顿）」；权益列表里放在 **展示类广告上一档**（见会员 design） |

## 交互摘要（目标态）

```
[1顿] [2顿] [3顿] [4顿] [5顿] [6顿] [自定义|N顿]
                                         ↓
                    非会员且未解锁 → 半屏：看广告解锁 / 开通会员
                                         ↓
                         步进 1～10 顿   [取消] [确认]
```

- 点快捷 1～5：直接写入对应 `mealSlots`，自定义芯片文案回到「自定义」。  
- 自定义确认后即使等于某快捷数，**仍保持自定义高亮**（与旧规则一致）。  
- 阶段 1 若激励广告未通：自定义入口主推开通会员；可保留「看广告」灰态或隐藏。

## 数据

- `scene.mealSlots: { meal: "other", label?: string }[]`，`1 ≤ length ≤ 10`（会员/解锁）或 `≤ 6`（免费）。  
- 废弃：`customLunchCount` / `customDinnerCount`、午晚 `DAILY_SLOT_PRESETS`、`buildDailySlotsFromCounts(lunch, dinner)`。  
- 可选：`users.dailyMealCustomUnlockDay: 'YYYY-MM-DD'`（上海日；激励完播后写入，当日可自定义 ≤10）。  
- 云函数：按 **slot 个数** 拆顿；勿按 `meal === lunch|dinner` 分支。

## 展示

| 面 | 规则 |
|----|------|
| 推荐页顿标题 | `meals.length > 1` 时显示 `第N顿`（来自 `slot.label`）；单顿可不显示顿标 |
| 场景条 | `mealSlotsSummary` / 回退文案为 **`N顿`**（如 `3顿`），禁止「一顿晚饭」「午饭①、晚饭①」拼接 |
| 已选方案 | `mealLabel` / `displayLabel` 同「第N顿」；`sceneSummary` 顿次同场景条 |

## 埋点

- `confirm_slot_pick`：`{ mode: 'preset'|'custom', mealCount }`；停用 `lunchCount` / `dinnerCount`。  
- `daily_meal_custom_gate_show` / `_ad` / `_member`（自定义门槛）。  
- `daily_meal_custom_unlock`（广告解锁成功）。

## 非范围

- 午晚差异化出菜、午饭简配、绑日历日  
- 恢复「一顿晚饭 / 一顿午饭 / 1午+1晚」  
- 聚会改成与日常同一套 6/10 规则（除非另开需求）
