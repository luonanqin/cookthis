# 需求摘要：跳过引导后的画像补全与常驻提醒

日期：2026-10-19  
用途：交给实现 / 技术方案 agent；产品定稿摘要，非实现细节。  
权威正文：`doc/需求概述.md` 模块 2（收集时机、轻量补全、常驻提醒）。

---

## 1. 背景与目标

- 允许新用户「先逛逛」跳过完整 onboarding，**不挡**确认食材 → 出推荐。  
- 无完整画像时仍可推荐（忌口空=不硬排除；品类/菜系中性；人数按成员或场景现填）。  
- 缺的是「准」不是「能不能推」；优先避免踩忌口。  
- 跳过引导 / 跳过轻量层后，用**不可关闭**的弱提醒把用户导回补全。

---

## 2. 已有能力（保持）

### 2.1 完整引导（onboarding）

- 路径：首页引导 / 「我的」。  
- 可跳过；跳过后 `onboardingDone` 可为 false。  
- 含：忌口、菜式品类、菜系、成员、搭配/用餐时间/城市等（详见用户画像详设）。

### 2.2 日常轻量补全弹层（全屏/半屏一次）

| 项 | 约定 |
|----|------|
| 时机 | **日常**确认食材与场景之后、`recommend.create` 之前 |
| 触发 | `familyAvoids` 为空，且尚未处理过该弹层（`profileLitePromptedAt` 等） |
| 不触发 | 聚会；已有忌口；已保存或已跳过该层 |
| 内容 | ① 家庭忌口（主）② 爱吃什么可选（火锅/面食等 → `dishFormPrefs`） |
| 不收 | 人数、搭配、成员、城市、菜系、预算 |
| 主按钮 | 保存并看方案 |
| 次按钮 | 暂时跳过 → 仍出方案 |
| 频控 | 保存或跳过任一后，**不再反复弹此全屏层** |

---

## 3. 新增 / 强化：常驻提醒（本次需求重点）

### 3.1 推荐页

- **顶栏小字提醒**，**不可关闭**（无 ×；不靠用户关掉，只靠缺口消失）。  
- 仍存在「提醒缺口」（§3.3）时展示。  
- 可点开**快捷补充**：表单与 **§2.2 轻量补全同款**（忌口 + 可选爱吃什么）。  
- 保存后：**必须刷新当前推荐结果**（按新忌口 / 可选品类偏好重新 `create` 或等价重跑，替换页上方案列表；不要只改顶栏、旧方案留着）。缺口若已消则顶栏消失。

### 3.2 「我的」页

- 列表顶或项旁**弱提醒**，**不可关闭**。  
- 可按缺口拆多条（忌口 / 成员 / 城市 / 菜系），点进对应编辑。  
- 某缺口补全后该项消失；全部满足则整块提醒消失。

### 3.3 「我的」提醒保持 / 消失标准

| # | 缺口 | 保持提醒直到 | 说明 |
|---|------|--------------|------|
| 1 | 家庭忌口未表态 | `familyAvoids.length > 0` **或** 用户明确「我家无忌口」 | 仅跳过轻量层 **不算**已表态；建议字段如 `familyAvoidsNone` / `familyAvoidsConfirmedAt` |
| 2 | 无成员 | `members.length ≥ 1` | 含本人 |
| 3 | 无城市 | `city` 非空 | |
| 4 | 菜系未表态 | 任一菜系 `prefer`/`avoid`，**或** 明确「全部一般 / 暂无偏好」 | 建议 `cuisinePrefsConfirmedAt`；从未编辑过则继续提醒 |

**不纳入必消提醒**：用餐时间、做饭预算、默认搭配、品类细调（缺了仍能推）。

### 3.4 与全屏轻量层的关系

- 全屏轻量层：一生（或每用户）在触发条件下最多认真打扰一次。  
- 常驻条：跟缺口走，可多次进入快捷补充，**不是**再弹一次强制全屏。

---

## 4. 非目标

- 不因画像不全而禁止 `recommend.create` / 禁止进推荐页。  
- 不在进场确认、菜场规模弹层上再叠强制问卷。  
- 推荐页 /「我的」提醒不做「关闭后 N 天再出现」的可关闭逻辑（产品要求不可关）。

---

## 5. 技术方案需覆盖的点（给设计 agent 的清单）

1. 缺口判定函数（前端展示 + 可选云端字段）。  
2. `familyAvoidsNone` / `cuisinePrefsConfirmedAt`（或等价）读写 API（`profile`）。  
3. 推荐页顶栏 UI + 快捷补充组件复用轻量补全。  
4. 「我的」提醒 UI 与跳转。  
5. 保存忌口后：会话内用户缓存刷新；**若来源为推荐页顶栏快捷补充 → 保存成功后立刻重跑推荐并刷新页上方案**（busy/空结果态与正常 create 一致）。  
6. 埋点建议：`profile_reminder_show` / `profile_lite_quick_save`（含来源 `recommend_banner` | `mine` | `pre_create_sheet`）。  
7. 与现有 `profileLitePromptedAt`、`onboardingDone` 的独立性说明。
