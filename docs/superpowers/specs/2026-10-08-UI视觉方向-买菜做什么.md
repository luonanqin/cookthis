## 规则

- 主按钮实心主色 + 白字；次按钮白底描边主色（`.btn-outline`）
- 按下态：主按钮加深（`--color-primary-pressed`），描边按钮填浅底；`view` 可点区域用 `hover-class="tap-hover"`
- 半屏共用 `.mask` / `.sheet`
- 少阴影、无紫渐变、无厚装饰
