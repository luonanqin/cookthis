# 菜谱难度编辑 Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `tools/alias-editor` 增加第四 Tab「难度」，按三档浏览菜谱、草稿改档、确认后写回 `recipes-builtin.json`，并复用「导出 for-import」。

**Architecture:** 纯函数模块 `recipe_difficulty.py` 负责分桶/校验/批量更新；`server.py` 增加 GET/PUT/POST；`index.html` 增加左栏三档 + 右侧三列网格 + 确认/脏切换弹窗。草稿仅前端内存。

**Tech Stack:** Python 3、stdlib `http.server`、现有 alias-editor 前端、pytest。

## Global Constraints

- `difficulty` 枚举仅 `easy` \| `home` \| `advanced`
- 左栏文案：轻松上手 / 家常水平 / 进阶一点（与引导一致）
- 点选三档**不写盘**；仅「确认修改」`PUT` 批量写 `recipes-builtin.json`
- 缺 `difficulty` 的菜按 `home` 分桶展示；确认改档时写入显式字段
- 草稿仅浏览器内存；刷新丢草稿
- 有草稿时切左栏或切 Tab → 弹窗三选：保存并切换 / 放弃并切换 / 取消
- 「导出 for-import」跑 `scripts/import-recipes.js`；有草稿时前端先拦
- 不改小程序/云函数；不自动导入云库
- 别名 / 忌口 / 城菜行为不得回归

```python
"""菜谱难度分桶与批量更新（recipes-builtin.difficulty）。"""
from __future__ import annotations

from typing import Any

DIFFICULTY_LEVELS = ("easy", "home", "advanced")
DIFFICULTY_LABELS = {
    "easy": "轻松上手",
    "home": "家常水平",
    "advanced": "进阶一点",
}


def effective_difficulty(row: dict[str, Any] | None) -> str:
    d = (row or {}).get("difficulty")
    if d in DIFFICULTY_LEVELS:
        return str(d)
    return "home"


def summarize_difficulty_recipe(row: dict[str, Any]) -> dict[str, Any]:
    return {
        "id": row.get("id"),
        "name": row.get("name"),
        "mainIngredients": list(row.get("mainIngredients") or []),
        "difficulty": effective_difficulty(row),
    }


def group_by_difficulty(
    recipes: list[dict[str, Any]],
) -> dict[str, list[dict[str, Any]]]:
    by: dict[str, list[dict[str, Any]]] = {k: [] for k in DIFFICULTY_LEVELS}
    for row in recipes or []:
        summary = summarize_difficulty_recipe(row)
        by[summary["difficulty"]].append(summary)
    for k in DIFFICULTY_LEVELS:
        by[k].sort(key=lambda r: str(r.get("name") or ""))
    return by


def counts_by_difficulty(by: dict[str, list[dict[str, Any]]]) -> dict[str, int]:
    return {k: len(by.get(k) or []) for k in DIFFICULTY_LEVELS}


def apply_difficulty_changes(
    recipes: list[dict[str, Any]],
    changes: dict[str, str],
) -> tuple[list[str], list[str]]:
    if not isinstance(changes, dict):
        raise ValueError("changes must be object")
    cleaned: dict[str, str] = {}
    for rid, level in changes.items():
        rid_s = str(rid or "").strip()
        level_s = str(level or "").strip()
        if not rid_s:
            continue
        if level_s not in DIFFICULTY_LEVELS:
            raise ValueError(f"invalid difficulty: {level_s}")
        cleaned[rid_s] = level_s
    by_id = {str(r.get("id") or ""): r for r in recipes}
    updated: list[str] = []
    missing: list[str] = []
    for rid, level in cleaned.items():
        row = by_id.get(rid)
        if row is None:
            missing.append(rid)
            continue
        row["difficulty"] = level
        updated.append(rid)
    return updated, missing
```

### Task 3: `index.html` 难度 Tab UI

**Files:**
- Modify: `tools/alias-editor/index.html`

**Interfaces:**
- Consumes: GET/PUT `/api/recipe-difficulty`；POST export；现有 `setMode` / `setStatus` / 顶栏按钮显隐模式

UI 要求（摘自 design）：

1. Tab 按钮「难度」；`mode === 'difficulty'`
2. 左栏 `#diff-nav`：三档 + 落盘计数
3. 右侧 `#diff-grid`：`display:grid; grid-template-columns: repeat(3, 1fr)`（`@media` 可降到 2/1）
4. 每卡：菜名、主料（`mainIngredients.join('、')`）、三按钮；高亮 = `draft.get(id) ?? row.difficulty`
5. `Map` 草稿：点选若等于落盘档则 `delete`，否则 `set`
6. `#btn-diff-confirm`：有草稿才 enable；PUT `{ changes: Object.fromEntries(draft) }`；成功清草稿并刷新
7. `#btn-diff-export`：有草稿则 `alert`/弹窗要求先确认或放弃；否则 POST export（可与城菜共用同一导出按钮在难度态也显示，或独立 `btn-diff-export` 文案同「导出 for-import」）
8. 切左栏 / `setMode` 离开难度：若 `draft.size>0`，`confirm` 不够用三按钮——用自定义小 modal：

```html
<dialog id="diff-dirty-dialog">
  <p>有未保存的难度修改，是否保存？</p>
  <button id="diff-dirty-save">保存并切换</button>
  <button id="diff-dirty-discard">放弃并切换</button>
  <button id="diff-dirty-cancel">取消</button>
</dialog>
```

切换流程：记录 `pendingNav` / `pendingMode` → 打开 dialog → save 则先 `confirmDifficulty()` 成功再执行切换；discard 则 `draft.clear()` 再切换；cancel 关闭。

**注意：** 改 `setMode` 时，从任意 mode 切到非 difficulty、或 difficulty 内切档，都要走脏检查。进入难度时 `loadDifficulty()`。

城菜的「导出 for-import」在难度态也应可用（design：另按钮）。实现：难度态显示 `#btn-city-export` **或** 新 `#btn-diff-export` 调同一 API；推荐新按钮调 `/api/recipe-difficulty/export-import`，避免城菜按钮在难度态语义混乱。

关键渲染片段（实现时嵌入现有脚本风格）：

```javascript
const DIFF_ORDER = ['easy', 'home', 'advanced'];
const DIFF_LABELS = { easy: '轻松上手', home: '家常水平', advanced: '进阶一点' };
let diffBy = { easy: [], home: [], advanced: [] };
let diffCounts = { easy: 0, home: 0, advanced: 0 };
let currentDiff = 'easy';
/** @type {Map<string, string>} */
let diffDraft = new Map();

function effectiveShownDifficulty(row) {
  return diffDraft.has(row.id) ? diffDraft.get(row.id) : row.difficulty;
}

function renderDiffGrid() {
  const list = diffBy[currentDiff] || [];
  $diffGrid.innerHTML = '';
  for (const row of list) {
    const card = document.createElement('div');
    card.className = 'diff-card';
    const shown = effectiveShownDifficulty(row);
    const mains = (row.mainIngredients || []).join('、') || '（无主料）';
    card.innerHTML = `<div class="diff-name"></div><div class="diff-mains"></div><div class="diff-levels"></div>`;
    card.querySelector('.diff-name').textContent = row.name || row.id;
    card.querySelector('.diff-mains').textContent = mains;
    const levels = card.querySelector('.diff-levels');
    for (const lv of DIFF_ORDER) {
      const b = document.createElement('button');
      b.type = 'button';
      b.textContent = DIFF_LABELS[lv].slice(0, 2); // 轻松 / 家常 / 进阶 — 或用全称
      // Prefer short labels: 轻松 / 家常 / 进阶
      b.textContent = { easy: '轻松', home: '家常', advanced: '进阶' }[lv];
      if (shown === lv) b.classList.add('active');
      b.addEventListener('click', () => {
        if (lv === row.difficulty) diffDraft.delete(row.id);
        else diffDraft.set(row.id, lv);
        syncDiffConfirmEnabled();
        renderDiffGrid();
      });
      levels.appendChild(b);
    }
    $diffGrid.appendChild(card);
  }
}
```

按钮文案用 **轻松 / 家常 / 进阶**（卡片内短标签）；左栏用全称 + 计数。
