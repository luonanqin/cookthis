**Goal:** 首页「今天菜场有什么」先走 `meals.confirmCandidates` 弹层（有锚点才弹），勾选后 `confirmWrite`；「记一下吃了什么」手动写入 `meal_logs`；推荐 `create` 消费近 7 日同菜名硬排除。验收以 **`npm test` 为主**，人工点验暂缓。

**Architecture:** 候选组装与去重为可单测纯函数；`meals` 云函数分发 confirmCandidates / confirmWrite / addManual / list；小程序首页半屏勾选；记录页简单表单；`homePlans` 增 `recentDishNames` 硬排除并 vendor 同步。

**Tech Stack:** 同前；`node --test`；新建 `cloudfunctions/meals`。

## Global Constraints

- 采纳推荐 **不** 写 `meal_logs`（仅进场确认 / 手动写）。  
- 无锚点 / 最新锚点已 `entryConfirmHandled` / 候选空 → **不弹层**，直达确认页；**不**回退到更早会话。
- 锚点：近 14 天 recommendations 中有 acceptedAt 或 engagedAt 的会话里，取锚点时刻最晚的**一条**；时刻 = 该条上有的 `acceptedAt`/`engagedAt` 取 max。
- 菜名：采纳用 `acceptedPlanIndex`，停留用 `engagedPlanIndex`；同条且时刻并列优先采纳 index。  
- 近期已记录：`meal_logs.createdAt >=` 锚点时刻 的 dishNames。  
- 弹层默认全不选；**确认（含勾 0 道）或跳过**均将该锚点标 `entryConfirmHandled=true`，**下次同锚点不弹**；跳过不写菜，确认只写勾选项。  
- 语音 / 拍照：**本切片不做**（入口可不露或 toast）。  
- 不做：完整画像、非常规方案、埋点全表、广告。
