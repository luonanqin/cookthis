# MVP 缺口补齐（除语音）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 补齐 onboarding、推荐成员忌口/主料新鲜度软降权、埋点业务事件（无语音/拍照）、购买清单广告位；**语音记饮食留到最后不做本计划。**

**Architecture:** 降权逻辑进 `homePlans` 可单测；onboarding 独立页 + `profile.completeOnboarding`；`track()` 在关键路径打事件；购物页按日常/非日常插原生广告容器（unitId 可配置占位）。

**Tech Stack:** 同前；`node --test`；微信 `<ad>` 组件。

## Global Constraints

- 语音记饮食 / 语音补菜 / 拍照：**本计划不做**。  
- 家庭忌口仍硬排除；成员忌口仅软降权。  
- 近 7 日同菜名仍硬排除；主料重叠仅软降权。  
- 广告：决策路径（确认/推荐交互）不插；主位在购买清单；日常 1 条、非日常可 2 条；unitId 用配置常量，未配置则隐藏。  
- 验收：`npm test` 必过；人工暂缓。
