# 用户序号与首次仪式 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 注册时原子分配稳定 `userNo`；「我的」昵称下常驻「第 N 位大厨」；每账号首次进「我的」播轻蒙层数字滚动仪式一次；公开昵称/分享不含 N。

**Architecture:** 云库集合 `counters` 文档 `userNo` 用 `_.inc(1)` + **事务读回**分配下一号（禁止无锁 max+1）。`auth.login` 建新用户时写入；老用户一次性脚本按 `createdAt`/`uid` 回填。`profile.ackUserNoReveal` 写 `userNoRevealSeenAt`。「我的」读 session/`profile.get` 展示小字 + 条件蒙层。

**Tech Stack:** 微信云开发 Node；小程序原生；`node --test`；回填用云函数临时 action 或 Node + 云开发 CLI（与项目现有脚本风格一致）。

**Spec:** `docs/superpowers/specs/2026-11-16-用户序号与首次仪式-design.md`

## 实现拍板

| 项 | 本计划选定 |
|----|------------|
| 原子序号 | 集合 `counters`，docId=`userNo`，字段 `value: number`；`allocateUserNo(db)` 事务内读改写 |
| API 回包 | `userNo: number\|null`；`userNoRevealSeen: boolean`（由 `userNoRevealSeenAt` 派生） |
| 本地防闪 | storage `cookthis_user_no_reveal_seen` = `1`（与服务端双写；以服务端为准） |
| 滚动 | span=`min(80, max(30, N))` 若 N&lt;30 则从 0；时长 1.5s；ease-out |
| 减弱动效 | `shouldAnimateUserNoReveal()`：可读 `wx.getAppBaseInfo`/`getSystemInfo` 若无字段则默认 true；蒙层仍出、数字定格 |
| 分享 | **不**改 `share` 快照字段；确认 `sharerNickname` 仅 nickname |

## Global Constraints

- 默认昵称逻辑不变（`大厨`+短码），**永不**把 `userNo` 拼进 nickname。  
- 仅本人 `login`/`profile.get`/`ackUserNoReveal` 可见 `userNo`；列表/分享禁止。  
- 已有 `userNo` 不改号。  
- 不在首页/引导强制插播。

### Task 1: `userNo` 辅助纯函数 + 单测

**Files:**
- Create: `cloudfunctions/_shared/userNo.js`
- Create: `cloudfunctions/_shared/userNo.test.js`

**Interfaces:**
- `formatUserNoLabel(n) →` `第 ${n} 位大厨`；非法返回 `''`
- `isValidUserNo(n) →` 正整数
- `revealStartValue(n, spanPreferred=50) → number`（`max(0, n - span)`，n≤span 则 0；span clamp 30～80）
- `easeOutCubic(t) →` 0..1

```js
'use strict'
function isValidUserNo(n) {
  return Number.isInteger(n) && n >= 1
}
function formatUserNoLabel(n) {
  return isValidUserNo(n) ? '第 ' + n + ' 位大厨' : ''
}
function revealStartValue(n, spanPreferred) {
  if (!isValidUserNo(n)) return 0
  let span = Number(spanPreferred)
  if (!Number.isFinite(span)) span = 50
  span = Math.min(80, Math.max(30, Math.floor(span)))
  if (n <= span) return 0
  return n - span
}
function easeOutCubic(t) {
  const x = Math.min(1, Math.max(0, Number(t) || 0))
  return 1 - Math.pow(1 - x, 3)
}
module.exports = { isValidUserNo, formatUserNoLabel, revealStartValue, easeOutCubic }
```

### Task 2: 原子分配 + `auth.login` 写入

**Files:**
- Create: `cloudfunctions/auth/allocateUserNo.js`（云函数包内，用 `db.runTransaction`）
- Modify: `cloudfunctions/auth/index.js`
- Modify: 现有用户回包与新建用户回包

**Interfaces:**
- `allocateUserNo(db) → Promise<number>`

```js
'use strict'
/**
 * 原子取下一 userNo。集合 counters / doc userNo / 字段 value。
 * 首次自动建 doc value=0 再 inc。
 */
async function allocateUserNo(db) {
  const _ = db.command
  const ref = db.collection('counters').doc('userNo')
  const next = await db.runTransaction(async (tx) => {
    let snap
    try {
      snap = await tx.get(ref)
    } catch (e) {
      snap = null
    }
    const data = snap && snap.data
    const cur = data && typeof data.value === 'number' ? data.value : 0
    const value = cur + 1
    if (data) {
      await tx.update(ref, { data: { value, updatedAt: db.serverDate() } })
    } else {
      await tx.set(ref, { data: { value, updatedAt: db.serverDate() } })
    }
    return value
  })
  return next
}
module.exports = { allocateUserNo }
```

> 若当前基础库 `tx.get`/`set` API 签名与上略有出入，按微信云开发**当前** Transaction 文档改写，但必须保证同事务内读+写，禁止「update inc 后再无锁 get」。

新建用户 `users.add` 增加：

```js
const userNo = await allocateUserNo(db)
// data: { …, userNo, userNoRevealSeenAt: null }
```

`login` 返回（新老用户）：

```js
userNo: isValidUserNo(user.userNo) ? user.userNo : null,
userNoRevealSeen: !!(user.userNoRevealSeenAt)
```

老用户若缺 `userNo`：回包 `userNo: null`（等回填脚本）；**不要**在每次 login 抢号（避免乱序）。

### Task 4: 老用户回填脚本

**Files:**
- Create: `scripts/backfill-user-no.md`（操作说明）+ `scripts/backfill-user-no.js`（若可用云开发 Node SDK）**或** 云函数临时 `action: 'adminBackfillUserNo'`（adminKey，一次性）

**算法：**

1. 拉取所有 `users`（分页），过滤尚无合法 `userNo` 的。  
2. 已有 `userNo` 的求出 `maxExisting`。  
3. 待填列表按 `createdAt` 升序，同毫秒按 `uid` 字符串升序。  
4. 从 `max(maxExisting, counters.value)` 起连续赋号；同时把 `counters.userNo.value` 更新为最终 max。  
5. 幂等：已有值跳过。

**禁止**在生产对已有号重排。

**js 要点：**

```js
onShow() {
  // …现有 load
  this._maybeStartUserNoReveal()
},

_maybeStartUserNoReveal() {
  const u = getUser() || {}
  const n = u.userNo
  if (!isValidUserNo(n)) return
  if (u.userNoRevealSeen) return
  try {
    if (wx.getStorageSync('cookthis_user_no_reveal_seen')) return
  } catch (e) {}
  const animate = shouldAnimateUserNoReveal()
  this.setData({
    showUserNoReveal: true,
    userNoLabel: formatUserNoLabel(n),
    revealDisplay: animate ? revealStartValue(n) : n,
    revealDone: !animate
  })
  if (animate) this._runRevealAnimation(n)
  track('user_no_reveal_show', { userNo: n })
},

onUserNoRevealAck() {
  this.setData({ showUserNoReveal: false, revealDone: true })
  try { wx.setStorageSync('cookthis_user_no_reveal_seen', 1) } catch (e) {}
  patchUser({ userNoRevealSeen: true })
  callCloud('profile', { action: 'ackUserNoReveal' }).catch(() => {})
  track('user_no_reveal_ack', {})
}
```

滚动：`requestAnimationFrame` 或 `setInterval(16)`，`t=(now-start)/1500`，`display = round(start + (N-start)*easeOutCubic(t))`，结束 `revealDone=true`。

样式：小字 `user-no` 用 `--color-text-secondary` / 较小 `--fs-*`；蒙层对齐现有 `mask` + 居中卡片。

点遮罩：可关并同样 ack（设计允许点遮罩关）。
