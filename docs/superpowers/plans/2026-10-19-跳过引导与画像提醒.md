# 跳过引导与画像常驻提醒 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.  
> **Handoff:** 本计划供独立 agent 按 Task 顺序实现；勿改需求口径；实现完把设计状态标为已实现。

**Goal:** 在跳过完整引导 / 跳过全屏轻量补全后，用不可关闭的推荐页顶栏与「我的」缺口提醒导回补全；推荐页快捷补充保存后 `recommend.create` 刷新方案。

**Architecture:** 纯函数 `computeProfileGaps`（`_shared` + 小程序 vendor）。`users` 增加 `familyAvoidsNone` / `familyAvoidsConfirmedAt` / `cuisinePrefsConfirmedAt`；`profile` 扩展读写与两个短 action。抽出 `profile-lite-form` 组件给确认页全屏层与推荐页 sheet 共用。推荐页顶栏只盯忌口未表态；「我的」列四个缺口。

**Tech Stack:** 微信小程序原生；云函数 `profile` / `auth` / `recommend`；Node `node --test`（`npm test`）。

## Global Constraints

- 不因画像不全禁止 `recommend.create`。  
- 全屏轻量层频控（`profileLitePromptedAt` / `profileLiteSkipped`）**不变**；与表态字段**独立**。  
- 跳过轻量、轻量保存**空忌口**均 **不算**忌口已表态。  
- 忌口已表态：`familyAvoids.length > 0` **或** `familyAvoidsNone === true`。  
- 菜系已表态：任一 `prefer`/`avoid`，**或** 存在 `cuisinePrefsConfirmedAt`。  
- 推荐顶栏：`recommendBanner === familyAvoidsOpen` only；无 ×。  
- 推荐快捷保存后必须 **`recommend.create` 新会话**替换方案，禁止只改顶栏。  
- 不做「关闭后 N 天再出现」。  
- 画像详设 §2.1 / §4.3、技术设计 users 行**已有字段说明**；实现时补埋点表 + 设计状态。

```js
'use strict'

function hasCuisineStance(prefs) {
  const p = prefs || {}
  return Object.keys(p).some((k) => p[k] === 'prefer' || p[k] === 'avoid')
}

function computeProfileGaps(input) {
  const familyAvoids = (input && input.familyAvoids) || []
  const familyAvoidsNone = !!(input && input.familyAvoidsNone)
  const membersCount = Number(input && input.membersCount) || 0
  const city = (input && input.city) || ''
  const cuisinePrefs = (input && input.cuisinePrefs) || {}
  const cuisinePrefsConfirmedAt = input && input.cuisinePrefsConfirmedAt

  const familyAvoidsOpen = !(
    (Array.isArray(familyAvoids) && familyAvoids.length > 0) ||
    familyAvoidsNone
  )
  const membersOpen = membersCount < 1
  const cityOpen = !String(city).trim()
  const cuisineOpen =
    !hasCuisineStance(cuisinePrefs) && !cuisinePrefsConfirmedAt

  const gaps = []
  if (familyAvoidsOpen) gaps.push('family_avoids')
  if (membersOpen) gaps.push('members')
  if (cityOpen) gaps.push('city')
  if (cuisineOpen) gaps.push('cuisine')

  return {
    gaps,
    familyAvoidsOpen,
    membersOpen,
    cityOpen,
    cuisineOpen,
    anyOpen: gaps.length > 0,
    recommendBanner: familyAvoidsOpen
  }
}

module.exports = { computeProfileGaps }
```

- [ ] **Step 5: `_recreateRecommendAfterProfile`**

```js
_recreateRecommendAfterProfile() {
  let selected = []
  let scene = null
  try {
    const sel = wx.getStorageSync('cookthis_last_selected') || null
    selected = (sel && sel.selected) || []
    scene = (sel && sel.scene) || null
    const rec = wx.getStorageSync('cookthis_last_recommend') || null
    if (!scene && rec) scene = rec.scene
    if ((!selected || !selected.length) && rec && rec.selectedIngredients) {
      selected = rec.selectedIngredients
    }
  } catch (e) {}
  if (!selected.length || !scene) {
    this.setData({ busy: false })
    this.refreshProfileBanner()
    wx.showToast({ title: '无法刷新，请返回重选食材', icon: 'none' })
    return
  }
  return callCloud('recommend', { action: 'create', selected, scene })
    .then((result) => {
      const plans = (result && result.plans) || []
      const snap = {
        requestId: result.requestId,
        plans,
        scene,
        selectedIngredients: selected,
        emptyReason: result.emptyReason || null,
        swapCount: 0
      }
      try {
        wx.setStorageSync('cookthis_last_recommend', snap)
      } catch (e) {}
      this.applySnap(snap) // 现有方法；若无则 setData plans + empty 逻辑对齐
      // 重置 engage 相关内部状态（_visibleMs / _engagedSent）与换一批后一致
      this.refreshProfileBanner()
      this.setData({ busy: false })
      if (!plans.length) {
        wx.showToast({ title: '暂无方案，可返回改食材', icon: 'none' })
      }
    })
    .catch((err) => {
      console.error(err)
      wx.showToast({ title: '刷新失败', icon: 'none' })
      this.setData({ busy: false })
      this.refreshProfileBanner()
    })
}
```

若页面方法名不是 `applySnap`，对齐现有 `onLoad`/`_rerun` 写 snap 的路径。
