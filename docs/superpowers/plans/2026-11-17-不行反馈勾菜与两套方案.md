# 不行反馈勾菜与两套方案 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 「不行」改为原因选项卡+≤10 道按比例勾菜（一菜多原因、无大标题）；家常推荐目标套数改为 2。

**Architecture:** 纯前端工具函数从当前 `plans` 抽样候选菜；推荐页半屏状态机管理原因与勾选；云端仅把 `TARGET_PLAN_COUNT` / `maxPlans` 默认改为 2。Reject 请求可附带 `dishFeedback`，服务端本阶段可不消费。

**Tech Stack:** 微信小程序、云函数 Node、`node:test`

## Global Constraints

- 无面板标题「不太合适的原因（可选）」
- 候选菜 ≤10；按荤/素/汤比例；小标签区分荤素汤
- 一道菜可挂多个原因
- 家常最多 2 套；跳过/零勾选完成=换批；取消/遮罩=不换批

```js
const { describe, it } = require('node:test')
const assert = require('node:assert/strict')
const { buildRejectDishPool } = require('../../miniprogram/utils/rejectDishPool.js')

describe('buildRejectDishPool', () => {
  it('caps at 10 and keeps meat/veg/soup proportion', () => {
    const meat = Array.from({ length: 6 }, (_, i) => ({
      recipeId: 'm' + i,
      name: '荤' + i,
      meatVeg: 'meat'
    }))
    const veg = Array.from({ length: 3 }, (_, i) => ({
      recipeId: 'v' + i,
      name: '素' + i,
      meatVeg: 'veg'
    }))
    const soup = Array.from({ length: 2 }, (_, i) => ({
      recipeId: 's' + i,
      name: '汤' + i,
      meatVeg: 'soup'
    }))
    const plans = [
      { meals: [{ dishes: meat.concat(veg) }] },
      { meals: [{ dishes: soup }] }
    ]
    const pool = buildRejectDishPool(plans, { limit: 10 })
    assert.equal(pool.length, 10)
    const c = { meat: 0, veg: 0, soup: 0 }
    pool.forEach((d) => {
      c[d.meatVeg]++
    })
    // 6:3:2 of 11 → of 10 ≈ 5,3,2 (largest remainder)
    assert.equal(c.meat, 5)
    assert.equal(c.veg, 3)
    assert.equal(c.soup, 2)
    assert.ok(pool.every((d) => d.typeLabel))
  })

  it('dedupes by recipeId and ignores non meat/veg/soup', () => {
    const plans = [
      {
        meals: [
          {
            dishes: [
              { recipeId: 'a', name: '肉', meatVeg: 'meat' },
              { recipeId: 'a', name: '肉', meatVeg: 'meat' },
              { recipeId: 'n', name: '面', meatVeg: 'staple' }
            ]
          }
        ]
      }
    ]
    const pool = buildRejectDishPool(plans)
    assert.equal(pool.length, 1)
    assert.equal(pool[0].recipeId, 'a')
  })
})
```
