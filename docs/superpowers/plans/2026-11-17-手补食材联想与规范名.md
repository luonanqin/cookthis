# 手补食材联想与规范名 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 确认页补菜支持汉字/拼音联想；点选后以**规范名**写入 `selected`；未命中仍可自由添加并提示无法匹配；去重已勾选规范名；不改变本趟手补、回首页清空。

**Architecture:** MVP 方案 A——登录后已有 `ensureAliases()` 别名表；构建脚本用 `pypinyin` 预计算表面名 → `{ surface, canonical, py, initials }`，经 `catalog.getAliases`（或并列缓存）下发；小程序 `manualSuggest.js` 纯函数检索（前缀/包含/全拼/首字母），确认页防抖下拉。不引入小程序 npm 拼音包，**不**在 recommend 热路径做拼音。

**Tech Stack:** 小程序原生；`node --test`；Python3 + pypinyin（构建索引）；现有 `catalogCache` / `aliasMatch`。

**Spec:** `docs/superpowers/specs/2026-11-17-手补食材联想与规范名-design.md`

## 实现拍板

| 项 | 本计划选定 |
|----|------------|
| 检索形态 | **A**：本地索引；索引文件 `data/catalog/manual-suggest-index.json` |
| 下发 | 扩 `catalog.getAliases` 回包增加 `suggestIndex`（或同请求第二字段）；客户端 `ALIASES` 旁缓存 `cookthis_manual_suggest_v1` |
| 拼音 | 构建期 `pypinyin`；运行时只比字符串 |
| 候选上限 | **10** |
| 防抖 | **200ms** |
| 展示 | 芯片 `displayName \|\| name`；未匹配旁注「暂无法匹配菜谱」 |

## Global Constraints

- `selected[].name` = 匹配名（命中时 canonical）；展示可用 displayName。  
- 不把生词/拼音写入 aliases。  
- 与已勾选/已补同一 canonical → 提示已在列表，不重复 manuals。  
- `preserveSelection` 仍保留 manuals；回首页重进清空。

### Task 1: 检索纯函数（可注入条目，TDD）

**Files:**
- Create: `cloudfunctions/_shared/manualSuggest.js`
- Create: `cloudfunctions/_shared/manualSuggest.test.js`
- Sync: `miniprogram/utils/manualSuggest.js`

**Interfaces:**
- `normalizeQuery(q) →` trim，去空白；若全为 ascii 则 `toLowerCase()`
- `buildEntriesFromAliases(aliasesTable) →` 仅结构（无拼音）测试用；生产条目带 `py`/`initials`
- `suggestManualIngredients(query, entries, opts) → { candidates: [{ surface, canonical, label }], unmatchedHint: boolean }`
  - `opts.limit` 默认 10  
  - `opts.excludeCanonicals: Set|string[]` 已在列表的规范名  
- `resolveManualAdd(query, entries, opts) → { matched, name, displayName, canonical? }`  
  - 唯一强前缀命中或 `opts.picked` → matched  
  - 否则 free 文本 `matched:false`

**排序分（低分优先，稳定）：**

```
0 汉字 surface 前缀
1 汉字 canonical 前缀（surface≠canon 时）
2 汉字包含
3 py 前缀（query 为纯字母时）
4 initials 前缀（纯字母）
同档按 surface.length 升序，再 localeCompare
同一 canonical 只保留第一条（已见 canon 跳过）
```

```js
// 单测示例
it('xihong maps to 番茄 via py prefix', () => {
  const entries = [
    { surface: '西红柿', canonical: '番茄', py: 'xihongshi', initials: 'xhs' },
    { surface: '番茄', canonical: '番茄', py: 'fanqie', initials: 'fq' }
  ]
  const r = suggestManualIngredients('xihong', entries, { limit: 10 })
  assert.equal(r.candidates[0].canonical, '番茄')
  assert.equal(r.candidates.length, 1) // 合并
})

it('汉字 西红 命中', () => {
  const r = suggestManualIngredients('西红', entries)
  assert.ok(r.candidates.some((c) => c.canonical === '番茄'))
})
```

**已选规范名集合：**

```js
_selectedCanonicalSet() {
  const set = new Set()
  // 已勾选 seasonal/yearRound 的 name（多为规范/展示名）→ aliasIndex.canonicalOf
  // 已有 manuals 的 name
  return set
}
```

**输入防抖：**

```js
onManualInput(e) {
  const v = e.detail.value
  this.setData({ manualInput: v })
  clearTimeout(this._suggestTimer)
  this._suggestTimer = setTimeout(() => this._refreshManualSuggest(v), 200)
},

_refreshManualSuggest(q) {
  const entries = this._suggestEntries || []
  const r = suggestManualIngredients(q, entries, {
    limit: 10,
    excludeCanonicals: this._selectedCanonicalSet()
  })
  if ((r.candidates || []).length) {
    track('ingredient_manual_suggest_show', {
      queryLen: String(q || '').trim().length,
      hitCount: r.candidates.length
    })
  }
  this.setData({
    manualSuggestions: r.candidates,
    manualSuggestEmpty: !!(String(q || '').trim() && !r.candidates.length)
  })
}
```

**点选候选：**

```js
onPickManualSuggest(e) {
  const canonical = e.currentTarget.dataset.canonical
  const surface = e.currentTarget.dataset.surface
  this._commitManual({
    matched: true,
    name: canonical,
    displayName: surface,
    canonical,
    via: 'pick'
  })
}
```

**添加按钮 / confirm：**

```js
addManual() {
  const q = (this.data.manualInput || '').trim()
  if (!q) return
  const entries = this._suggestEntries || []
  const sug = this.data.manualSuggestions || []
  let resolved
  if (sug.length === 1) {
    resolved = {
      matched: true,
      name: sug[0].canonical,
      displayName: sug[0].surface,
      canonical: sug[0].canonical,
      via: 'pick'
    }
  } else {
    resolved = Object.assign(
      { via: 'free' },
      resolveManualAdd(q, entries, { excludeCanonicals: this._selectedCanonicalSet() })
    )
  }
  this._commitManual(resolved)
}
```

**`_commitManual`：**
- 若 `matched` 且 canonical 已在 set → `wx.showToast({ title: '已在列表中', icon: 'none' })`，清空输入，return  
- push manuals：

```js
{
  id: 'custom_' + Date.now(),
  name: resolved.name,
  displayName: resolved.displayName || resolved.name,
  canonical: resolved.canonical,
  matched: !!resolved.matched,
  source: 'manual'
}
```

- track `ingredient_manual_add` `{ matched, via }`；若 `!matched` 另打 `ingredient_manual_unmatched` `{ nameLen }`  
- 清空 input / suggestions

**wxml：**

```xml
<input placeholder="菜名或拼音" bindinput="onManualInput" bindconfirm="addManual" />
<view class="manual-suggest" wx:if="{{manualSuggestions.length}}">
  <view
    wx:for="{{manualSuggestions}}"
    wx:key="canonical"
    data-canonical="{{item.canonical}}"
    data-surface="{{item.surface}}"
    bindtap="onPickManualSuggest"
  >{{item.label}}</view>
</view>
<view wx:if="{{manualSuggestEmpty}}" class="manual-suggest-empty">无匹配，可仍添加（可能无法出菜）</view>
<!-- 已补 -->
<text class="name">{{item.displayName || item.name}}</text>
<text wx:if="{{item.matched === false}}" class="manual-unmatched">暂无法匹配菜谱</text>
```

`label` 在 suggest 里生成：surface===canonical ? surface : `${surface}（${canonical}）`。

`buildSelected`：继续用 `it.name`（已是规范名或原文）。
