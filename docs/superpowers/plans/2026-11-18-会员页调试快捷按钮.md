# 会员页调试快捷按钮 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在开发/体验版会员页底部提供调试按钮（开月/季/年、清会员、约 1 天后到期、重置首购），云端仅 `MEMBERSHIP_ALLOW_DEV_GRANT=1` 可用；开卡叠期与正式履约一致。

**Architecture:** 扩展 `createMembershipApi` 的 `devGrant` / 新增 `devClear` / `devExpireSoon` / `devResetFirstPurchase`，成功后统一 `return getStatus(uid)`。前端 `services/membership.js` 包一层；会员页 `showDevTools`（`develop|trial`）渲染页底调试区。

**Tech Stack:** 微信小程序 + 云函数 membership；`node --test`。

## Global Constraints

- 调试 UI 仅 `envVersion === develop || trial`
- 全部 `dev*` 需 `MEMBERSHIP_ALLOW_DEV_GRANT=1`，否则 `FORBIDDEN`
- `devGrant` 必须走 `fulfillPaidOrder` / `computeNewExpiry` 叠期，不得覆盖到期日
- `devExpireSoon` 故意覆盖为 `now+1d`（测临期）
- 支付 success 路径仍不得直写 `isMember: true`

- [ ] **Step 1: 写失败测试（叠期 / clear / expireSoon / reset / FORBIDDEN）**

在 `index.test.js` 的 `describe('devGrant')` 旁扩展：

```js
const DAY_MS = 86400000
const { computeNewExpiry } = require('./membershipLogic.js')

describe('dev tools', () => {
  const DEV = Object.assign({ MEMBERSHIP_ALLOW_DEV_GRANT: '1' }, PAY_ENV)

  it('devGrant stacks month on month', async () => {
    const db = createMemoryDb()
    await seedUser(db)
    const a = await api(db, DEV).devGrant('user-1', 'month')
    assert.equal(a.ok, true)
    assert.equal(a.isMember, true)
    const firstExp = a.expiresAt
    const b = await api(db, Object.assign({}, DEV, { /* same NOW via deps */ })).devGrant('user-1', 'month')
    // use same nowMs: second call via createMembershipApi({ nowMs: NOW })
    assert.equal(b.expiresAt, computeNewExpiry(firstExp, 31, NOW))
  })

  it('devClear expires membership; forbids without flag', async () => {
    const db = createMemoryDb()
    await seedUser(db)
    await api(db, DEV).devGrant('user-1', 'month')
    assert.deepEqual(await api(db, PAY_ENV).devClear('user-1'), { ok: false, error: 'FORBIDDEN' })
    const cleared = await api(db, DEV).devClear('user-1')
    assert.equal(cleared.ok, true)
    assert.equal(cleared.isMember, false)
  })

  it('devExpireSoon sets ~1 day; grants month first if needed', async () => {
    const db = createMemoryDb()
    await seedUser(db)
    const res = await api(db, DEV).devExpireSoon('user-1')
    assert.equal(res.ok, true)
    assert.equal(res.isMember, true)
    assert.equal(Date.parse(res.expiresAt), NOW + DAY_MS)
  })

  it('devResetFirstPurchase restores first-buy offers', async () => {
    const db = createMemoryDb()
    await seedUser(db)
    await api(db, DEV).devGrant('user-1', 'month')
    const before = await api(db, DEV).getStatus('user-1')
    assert.equal(before.offers.find((o) => o.sku === 'month').isFirstPurchase, false)
    const after = await api(db, DEV).devResetFirstPurchase('user-1')
    assert.equal(after.offers.find((o) => o.sku === 'month').isFirstPurchase, true)
    const paid = (await db.collection('membership_orders').where({ uid: 'user-1', status: 'paid' }).get()).data
    assert.ok(paid.every((o) => o.ignoreForFirstPurchase === true))
  })
})
```

注意：`api()` 固定 `nowMs: NOW`；二次 `devGrant` 用同一 `api(db, DEV)` 即可叠期。
