# 成员 / 大中小老 / 访客 / 用餐人软分 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 成员列表为日常人数来源；确认页日常/聚会二分；聚会三档 `partyCounts` + 本场忌口、**不露搭配**、`suggestPartyCombo`（无小孩荤+1；总菜 n+种子随机1~2）；§3.0.8 软分；「我的」成员 CRUD；五档年龄。

**Architecture:** `_shared/members.js` 纯函数（年龄归一、大中小老、用餐人展开、软分 extras）+ 测试；profile 增删改后回写 `defaultPeopleCount`；confirm 日常写 `householdCounts`/`guestCounts`，非日常写 `partyCounts`+`partyAvoids`；recommend 用 `expandMealDiners`（日常 = members∪访客；非日常 = 仅 partyCounts 档位默认）；mine/onboarding 去掉可编辑默认人数。

**Tech Stack:** 微信小程序 + 云函数；`npm test`（`cloudfunctions/_shared/*.test.js`）；vendored `recommend/homePlans.js` 与 `_shared` 同步。

## Global Constraints

- 小=`5_15`，老=`60_plus`；不做学龄前 `0_2`/`3_5`
- 访客 / `partyCounts` 不写 `members`；写回日常只写 combo（及缓存成员数）
- 不随大/小/老自动改 `defaultCombo` / 当次荤素汤
- 软惩罚不硬删；日常家庭忌口硬排除；**非日常 `partyAvoids` 硬排除保持不变**
- 非日常软分用餐人 = 仅 `partyCounts` 档位默认，不并入档案成员个人忌口
- 同步修改 `_shared` 与 `cloudfunctions/recommend/` 下 vendored 副本（若存在）
