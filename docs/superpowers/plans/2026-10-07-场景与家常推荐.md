# 场景 + 家常推荐 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Slice 1 食材确认之后接上当次场景（日常 / 非日常 / 节日），调用 `recommend.create` 产出 1～3 套**家常**方案并展示；用户能从确认页一路看到菜名。

**Architecture:** 场景表单落在确认页下半区（或同流程下一屏）；纯函数负责 `suggestComboByPeople` 与家常组菜；云函数 `recommend` 读 `recipes` + 食材 `avoidTags`，写 `recommendations`；推荐页只展示方案（本切片不做换一批 / 可以 / 清单）。

**Tech Stack:** 同 Slice 1（原生小程序 + 云函数 Node + `node --test`）；沿用 `callCloud` / `session`；云函数继续 vendoring `_shared` 副本。

## Global Constraints

- 业务主键 **uid**；openid 只在服务端 `user_identities`。
- 日常：预填 `defaultPeopleCount` + `defaultCombo`；非日常：不预填，填人数后 `suggestComboByPeople`；非日常 `partyAvoids` 当次硬排除且**不写回**画像。
- 节日：`holidayId`（稳定代号）+ `holidayDate`；列表今天起 30 天。
- 几顿：日常可分午/晚；非日常默认 1 顿 `meal:other`，不选午晚；**无 dayOffset**。
- 推荐硬排除：按菜谱食材 → `ingredients.avoidTags` ∩ 忌口词表，**不用菜名**。
- 本切片 **只出 `planKind: home`**；不做火锅/面/饺、不做 swap/reject/accept/engage、不做购买清单、不做进场确认、不做完整画像引导、不做埋点全表（可打少量 `recommend_show` 可选）。
- 主料匹配：菜谱 `mainIngredients` 名称（或 id）须 ⊆ 用户 `selected` 名称集合（调味可缺）。

### Task 1: `suggestComboByPeople` + 单测

**Files:**
- Create: `cloudfunctions/_shared/suggestCombo.js`
- Create: `cloudfunctions/_shared/suggestCombo.test.js`

**Interfaces:**
- Produces: `suggestComboByPeople(n: number) => { meat: number, veg: number, soup: number }`
- 表：1→1-1-0；2→1-1-1；3→1-2-1；4–6→2-2-1；≥7→2-3-1；`n<1` 抛错或返回 null（测试约定：`n<1` → `null`）

- [ ] **Step 1: 写失败测试**

```js
const { describe, it } = require('node:test')
const assert = require('node:assert/strict')
const { suggestComboByPeople } = require('./suggestCombo.js')

describe('suggestComboByPeople', () => {
  it('maps table', () => {
    assert.deepEqual(suggestComboByPeople(1), { meat: 1, veg: 1, soup: 0 })
    assert.deepEqual(suggestComboByPeople(2), { meat: 1, veg: 1, soup: 1 })
    assert.deepEqual(suggestComboByPeople(3), { meat: 1, veg: 2, soup: 1 })
    assert.deepEqual(suggestComboByPeople(5), { meat: 2, veg: 2, soup: 1 })
    assert.deepEqual(suggestComboByPeople(8), { meat: 2, veg: 3, soup: 1 })
  })
  it('invalid n returns null', () => {
    assert.equal(suggestComboByPeople(0), null)
    assert.equal(suggestComboByPeople(-1), null)
  })
})
```

- [ ] **Step 2: Run → FAIL**

Run: `npm test`  
Expected: missing module

- [ ] **Step 3: 实现**

```js
'use strict'
function suggestComboByPeople(n) {
  const num = Number(n)
  if (!Number.isFinite(num) || num < 1) return null
  if (num === 1) return { meat: 1, veg: 1, soup: 0 }
  if (num === 2) return { meat: 1, veg: 1, soup: 1 }
  if (num === 3) return { meat: 1, veg: 2, soup: 1 }
  if (num <= 6) return { meat: 2, veg: 2, soup: 1 }
  return { meat: 2, veg: 3, soup: 1 }
}
module.exports = { suggestComboByPeople }
```

- [ ] **Step 4: Run → PASS**

- [ ] **Step 5: Commit**

```bash
git add cloudfunctions/_shared/suggestCombo.js cloudfunctions/_shared/suggestCombo.test.js
git commit -m "feat: add suggestComboByPeople helper with tests"
```

### Task 3: 家常组菜纯函数 + 单测

**Files:**
- Create: `cloudfunctions/_shared/homePlans.js`
- Create: `cloudfunctions/_shared/homePlans.test.js`

**Interfaces:**

```ts
// buildHomePlans(input) => { plans: Plan[], emptyReason?: string }
// input:
{
  recipes: Recipe[],
  ingredientsByName: Map<string, { avoidTags?: string[] }>, // name → meta；也可 id
  selectedNames: string[],
  scene: { combo: {meat,veg,soup}, mealSlots: MealSlot[], partyAvoids?: string[], mealType },
  familyAvoids: string[],
  excludedDishIds?: string[],
  maxPlans?: number // default 3
}
```

规则（本切片最小集）：

1. 候选：`enabled!==false`；`cities` 空或含 city（city 可先忽略，全全国）；主料每个 name ∈ selectedNames（大小写精确匹配种子中文名）  
2. 硬排除：解析菜谱所有主料+调味名 → 查 avoidTags；与 `(mealType==='daily' ? familyAvoids : (partyAvoids||[]))` 求交非空则丢  
3. `excludedDishIds` 丢弃  
4. 按 `meatVeg` 分桶；对每个 `mealSlot` 从桶中取 combo 数量的不重复 recipe；多顿之间尽量不重复 id  
5. 能凑满至少 1 顿完整 combo → 生成 1～`maxPlans` 套（用不同起始菜换序/打散）；否则 `{ plans:[], emptyReason:'cannot_fill_combo' }`  
6. 只产出 `planKind:'home'`

- [ ] **Step 1: 写测试**（固定小 recipes 夹具：猪肉土豆肉菜、青菜素菜、鸡蛋汤；selected 齐全应出 1 plan；忌 pork 应丢掉肉菜导致 empty 或无 meat）
