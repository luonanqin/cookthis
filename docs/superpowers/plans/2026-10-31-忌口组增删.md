> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 忌口 Tab 可增删忌口组；`avoidVocab` 以 major-minor 文件为真源；修掉 PUT 成员时把词表打回硬编码六码的缺陷；偏好页不动。

**Tech Stack:** Python 3、stdlib HTTP server、静态 HTML、pytest。

**Spec:** `docs/superpowers/specs/2026-10-31-忌口组增删-design.md`

## Global Constraints

- 新增只填中文 `label`，`id = gN`（现有 `^g(\d+)$` 最大 +1，无则 `g1`）。  
- 删除：确认后整组删（含 members）；原六码也可删。  
- 不改 `mine.js` / 推荐过滤。  
- 导出按当前 vocab ids 全量重算 builtin；不写云库。  
- 不做重命名、改 id、组排序。

import re

_G_ID = re.compile(r"^g(\d+)$")


def vocab_ids(vocab: list) -> set[str]:
    return {str(x.get("id") or "") for x in (vocab or []) if x.get("id")}


def next_g_id(vocab: list) -> str:
    nmax = 0
    for x in vocab or []:
        m = _G_ID.match(str(x.get("id") or ""))
        if m:
            nmax = max(nmax, int(m.group(1)))
    return f"g{nmax + 1}"


def add_avoid_group(vocab: list, members: dict, label: str) -> tuple[list, dict, str]:
    label = str(label or "").strip()
    if not label:
        raise ValueError("label required")
    vocab = [dict(x) for x in (vocab or [])]
    members = {k: list(v) for k, v in (members or {}).items()}
    if any(str(x.get("label") or "") == label for x in vocab):
        raise ValueError("duplicate label")
    nid = next_g_id(vocab)
    vocab.append({"id": nid, "label": label})
    members.setdefault(nid, [])
    return vocab, members, nid


def remove_avoid_group(vocab: list, members: dict, code: str) -> tuple[list, dict]:
    code = str(code or "").strip()
    vocab = [dict(x) for x in (vocab or [])]
    members = {k: list(v) for k, v in (members or {}).items()}
    if not any(x.get("id") == code for x in vocab):
        raise KeyError(code)
    vocab = [x for x in vocab if x.get("id") != code]
    members.pop(code, None)
    return vocab, members
```

改 `add_member`：`allowed_ids` 必填（或默认 `AVOID_IDS` 过渡）；未知 code 则 no-op。

def _validate_avoid_members(avoid_members: object, allowed: set[str]) -> str | None:
    if not isinstance(avoid_members, dict):
        return "avoidMembers must be object"
    for code, names in avoid_members.items():
        if code not in allowed:
            return f"unknown avoid code: {code}"
        if not isinstance(names, list):
            return f"avoidMembers[{code}] must be list"
    return None

async function createAvoidGroup() {
  const label = prompt('新忌口组名称（中文）');
  if (label == null) return;
  const r = await fetch('/api/avoid/vocab', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ label }),
  });
  const body = await r.json();
  if (!r.ok) throw new Error(body.error || r.statusText);
  avoidVocab = body.avoidVocab;
  avoidMembers = body.avoidMembers;
  currentAvoidCode = body.id;
  renderAvoidCodes();
  renderAvoidPool();
  renderAvoidMembers();
  setStatus('已新增忌口组: ' + label, 'ok');
}
```

每个组 chip：结构改为 label span + × span；× `stopPropagation`，`confirm` 后：

```javascript
async function deleteAvoidGroup(id, label) {
  const n = (avoidMembers[id] || []).length;
  if (!confirm(`删除「${label}」及其 ${n} 个成员？`)) return;
  const r = await fetch('/api/avoid/vocab?id=' + encodeURIComponent(id), { method: 'DELETE' });
  const body = await r.json();
  if (!r.ok) throw new Error(body.error || r.statusText);
  avoidVocab = body.avoidVocab;
  avoidMembers = body.avoidMembers;
  if (currentAvoidCode === id) {
    currentAvoidCode = avoidVocab[0] ? avoidVocab[0].id : null;
  }
  renderAvoidCodes();
  renderAvoidPool();
  renderAvoidMembers();
  setStatus('已删除忌口组: ' + label, 'ok');
}
```
