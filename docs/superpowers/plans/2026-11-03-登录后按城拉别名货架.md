# 登录后按城拉别名/货架 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 小程序包不再含别名/多城货架；登录后云函数按账号城下发并本地缓存（安全 #5）。

**Architecture:** 新云函数 `catalog`（`getAliases` / `getCityShelf`，货架只信 `users.city`）；客户端 `catalogCache` + `ensureLogin` 预拉、购物清单补拉、换城清缓存；删除包内 `aliases.js` / `city-shelves.js` 引用。

**Tech Stack:** 微信云开发 Node 云函数、小程序 `wx.storage`、现有 `callCloud` / `accessGuard` / `aliasMatch`。

## Global Constraints

- 别名补拉失败：只 `track`，不 Toast。
- 货架 API 忽略客户端 city。
- 不引入 CDN；首版不做内容 hash 自动刷新（靠 storage key `_v1`）。
