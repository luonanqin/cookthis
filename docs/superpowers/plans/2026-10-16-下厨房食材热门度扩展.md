# 下厨房食材热门度扩展 Implementation Plan

> **For agentic workers:** Implement task-by-task; steps use checkbox syntax.

**Goal:** Chrome MV3 扩展，按词表在 mbdbj.xiachufang.com 采集食材「做过」热度并导出 txt。

**Architecture:** popup 控制；content script 状态机驱动页面；background 负责 downloads；进度存 chrome.storage 并每次覆盖下载。

**Tech Stack:** Chrome Extension Manifest V3、原生 JS、无构建依赖。

## Global Constraints

- 仅匹配 `https://mbdbj.xiachufang.com/*`
- 每 10 个食材休息 5–10s；食材间 1–2s
- 卡住刷新重试最多 3 次；验证码直接暂停
- 输出中文分类名；非食材置底
