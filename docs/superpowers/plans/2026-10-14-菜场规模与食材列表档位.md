# 菜场规模与食材列表档位 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 预生成全国热度与分城小/中/大档时令·四季名单；确认页按 `marketScaleEffective` 只读对应档；首页在进场确认之后按定位规则弹出规模半屏；确认页可切换并即时刷新名单。

**Architecture:** Python 脚本构建 `ingredient-popularity.json` 与各城 `ingredients-by-scale.json`（不运行时算热度）。云函数 `ingredients` 改为按城+档读预生成文件并 shape 成现有 `seasonal` / `yearRound` 列表。`users` 存 choice/effective/锚点/历史。首页半屏 + 确认页轻链共用同款 UI；`marketScale` 纯函数可单测（派生、1km、30 分钟、是否弹层）。

**Tech Stack:** Python 3 + pytest（构建）；微信小程序 + 云函数 Node；`node --test`（`npm test`）。

**Spec:** `docs/superpowers/specs/2026-10-14-菜场规模与食材列表档位-design.md`（以 §一～§四 / §4.7 为准）

## Global Constraints

- 分类仅用 `ingredients-all-by-category.json`；城货架展示前映射到此类。  
- 热度全国一份；缺热度记 **1**；别名组计分 **max**，展示仍用当地名。  
- 分档：每类内小=⌈n/3⌉、中=⌈2n/3⌉、大=全部；**废除** 10/20/30 等绝对条数。  
- 运行时**不**现算热度；只读 `scales[effective]`。  
- 进场确认与规模半屏**禁止叠弹**；无定位不弹规模；遮罩不关层。  
- `default_medium` ≠ `medium`（展示文案可区分）；页内切换不受 30 分钟限制。  
- 本期**不做** implies、不做「我的」内改规模主路径。

- [ ] **Step 2: 实现步骤（对齐设计）**

1. 展平城货架所有当地名（忽略城内美团类名桶）。  
2. `canonical = aliasIndex.canonicalOf(local)`；`category = popularity[canonical].category` 或 by-category 反查；失败 → `unmapped.append(local)`，**不入档**。  
3. 每类候选按 `score` 降序，同分按通用名 `localeCompare`/`sorted` 稳定序。  
4. `ceil(n/3)` / `ceil(2n/3)` / 全量。  
5. 拆时令：`seasonal` 扁平集合 = 合并 `seasonal-ingredients.json` 所有 categories；当地名或 canonical **任一** ∈ 集合即算时令。  
6. 写出 `ingredients-by-scale.json`；`_meta.unmapped` + 构建结束 print 未映射数量。

```python
import math
def cut_tiers(ordered_names):
    n = len(ordered_names)
    if n == 0:
        return {"small": [], "medium": [], "large": []}
    return {
        "small": ordered_names[: math.ceil(n / 3)],
        "medium": ordered_names[: math.ceil(2 * n / 3)],
        "large": ordered_names[:],
    }
```

条目形态：`{"name": canonical, "displayName": local}`。同一 canonical 多当地名：按货架顺序保留**第一条**当地名作 display（或与 2026-10-20 购物清单优先异名策略对齐——本脚本简单取先出现的当地名即可，并在 `_meta` 注明）。
