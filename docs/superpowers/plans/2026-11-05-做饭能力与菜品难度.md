# 做饭能力与菜品难度匹配 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 引导内 3×5 选题测验写入 `users.cookSkill`；菜谱有效 `difficulty`（显式或 minutes+形态启发式）；推荐对 beginner×advanced 硬排除、差一档软降权；「我的」可重测覆盖档位。

**Architecture:** 纯函数 `cookSkill.js`（定档 + 有效难度 + 硬/软规则）放 `_shared` 并 vendor。`homePlans` 候选过滤加难度硬排，`softPenalty` 加难度软分。引导插一步「哪些菜你做得来？」；`completeOnboarding` / 新 action `saveCookSkillProbe` 写字段。15 道探针菜为小程序常量（带明确 difficulty）。可选脚本为 builtin 热门菜补显式 `difficulty`。

**Tech Stack:** 微信小程序；云函数 Node；`node --test`；可选 Python/Node 标注脚本。

**Spec:** `docs/superpowers/specs/2026-11-05-做饭能力与菜品难度-design.md`

## 实现拍板

| 项 | 本计划选定 |
|----|------------|
| 引导步位置 | 插在 **城市之后、菜系之前**：…所在城市 → **做饭水平** → 菜系 → 菜式（与「我的」重测入口独立；「我的」画像区不插整步，仅链到重测） |
| 探针菜 | 见 Task 1 常量 15 道（须在 catalog 有同名或纯展示用；**测验不依赖云库 id**） |
| 软降权分值 | `DIFFICULTY_SOFT_PENALTY = 20`（与 `cuisineSoftDelta` 的 `|PREFER_DELTA|` 同量级；忌口硬排仍在候选外） |
| 复杂形态 | `steam` / `hotpot` / `dumpling` / `bake`（若有）视为复杂；`stir_fry`/`braise`/`soup`/`noodle` 不单凭形态升 advanced |
| 可选落库 | 写 `cookSkillProbeAt` + `cookSkillProbeCounts`（便于调阈值） |
| 跳过 vs 零勾选完成 | 跳过：不写 `cookSkill`；点「下一步」且 nE=nH=nA 均 &lt;3（含全 0）→ 写 `beginner` |

## Global Constraints

- 不做自报三档 chip；不做成员级能力；不做行为校准。  
- 未填 / 跳过 → 推荐当 `home`（不硬排 advanced）。  
- 有显式 `difficulty` 不被启发式覆盖。  
- 重测点跳过/取消 **不**清空已有 `cookSkill`。  
- 时间预算 / `minutes` 耗时逻辑保持独立（本期可不接 cookBudget 过滤）。

**Interfaces:**

> 若某名不在 builtin：测验仍展示该文案（纯问卷）；推荐硬排只看菜谱 `difficulty` 字段。实现时可在 Task 6 脚本里给命中名写显式档。

启发式 `inferDifficulty(recipe)`：

```js
if (recipe.difficulty && DIFFICULTY_VALUES.includes(recipe.difficulty)) {
  return recipe.difficulty
}
const minutes = Number(recipe.minutes)
const forms = recipe.dishForms || []
const complex = forms.some((f) => COMPLEX_DISH_FORMS.includes(f))
if (Number.isFinite(minutes) && minutes <= 20 && !complex) return 'easy'
if ((Number.isFinite(minutes) && minutes >= 50) || complex) return 'advanced'
return 'home'
```

定档：

```js
function deriveCookSkill(counts) {
  const nA = Number(counts && counts.advanced) || 0
  const nH = Number(counts && counts.home) || 0
  if (nA >= PROBE_THRESHOLD) return 'skilled'
  if (nH >= PROBE_THRESHOLD) return 'home'
  return 'beginner'
}
```

硬/软：

```js
// skill×difficulty 矩阵
// beginner+advanced → hard
// beginner+home → soft 20
// home+advanced → soft 20
// else → 0 / false
```
