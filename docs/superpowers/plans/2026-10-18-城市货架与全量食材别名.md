# 城市货架与全量食材别名 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从美团清洗结果与 builtin 产出分城货架、按类全量食材、别名表与人工审核清单，并提供一次展开的匹配工具函数。

**Architecture:** 清洗脚本读 `data/catalog/review/` 三份清单；`build_ingredient_catalog.py` 把各城 `ingredients-cleaned.json` 导出为 `data/catalog/cities/{城}/ingredients.json`，再与 builtin（经类映射）合并为 `ingredients-all.json`；`aliases.json` + `alias_match.py` 做货架一次展开与菜谱 ⊆ 判断。

**Tech Stack:** Python 3（项目已有 `tools/meituan-automator/.venv`）、pytest、JSON/TXT 目录约定。

**Spec:** `docs/superpowers/specs/2026-10-18-城市货架与全量食材别名-design.md`

## Global Constraints

- 城市货架保留当地名，不做别名归一入库
- 分类先用美团类；builtin → 美团类用显式映射表，未映射进「未映射」
- 全量 = 各城货架 ∪ builtin；按类内字符串去重
- 匹配：货架一次别名展开，禁止按别名反复搜菜谱
- 分词词典从全量派生（可选步骤），不是人工主维护物
- 本计划不改推荐云函数 / App UI / 规模档

```python
# tools/meituan-automator/review_lists.py
from __future__ import annotations
from dataclasses import dataclass
from pathlib import Path

def load_name_set(path: Path) -> set[str]:
    if not path.is_file():
        return set()
    out: set[str] = set()
    for line in path.read_text(encoding="utf-8").splitlines():
        s = line.strip()
        if not s or s.startswith("#"):
            continue
        out.add(s)
    return out

def load_segment_hints(path: Path) -> dict[str, list[str]]:
    if not path.is_file():
        return {}
    out: dict[str, list[str]] = {}
    for line in path.read_text(encoding="utf-8").splitlines():
        s = line.strip()
        if not s or s.startswith("#") or "=" not in s:
            continue
        left, right = s.split("=", 1)
        parts = [p.strip() for p in right.split("+") if p.strip()]
        if left.strip() and parts:
            out[left.strip()] = parts
    return out

@dataclass(frozen=True)
class ReviewLists:
    reject: set[str]
    accept: set[str]
    segments: dict[str, list[str]]

def load_review_lists(review_dir: Path) -> ReviewLists:
    return ReviewLists(
        reject=load_name_set(review_dir / "reject.txt"),
        accept=load_name_set(review_dir / "accept.txt"),
        segments=load_segment_hints(review_dir / "segment-hints.txt"),
    )
```
