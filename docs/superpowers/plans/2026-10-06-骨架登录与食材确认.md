# 骨架 + 登录 + 静态食材确认 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭好原生小程序 + 云开发骨架，跑通微信登录拿到 `uid`（默认「大厨xxxx」），并用内置静态食材数据完成「时令主列表全选 + 四季常见计入」的确认页，输出一份可交给后续推荐的 `selected`。

**Architecture:** 原生微信小程序调用云函数；业务主键 `uid`，登录身份进 `user_identities`；食材主数据先放 `data/ingredients-builtin.json`，由云函数 `ingredients.list` 分层返回；纯逻辑（昵称短码、列表分层）放可单测的 Node 模块，云函数与小程序只做组装与展示。

**Tech Stack:** 微信小程序原生（WXML/WXSS/JS）、微信云开发（云函数 Node.js + 云数据库）、本地 `node --test`（或 Jest）测纯函数；本切片不引入 Taro / 自建 Node 服务。

## Global Constraints

- 原生小程序 + 云开发 + **uid** 账号层（见 `docs/superpowers/specs/2026-10-02-技术设计.md` §2.1）。
- 不自动拉微信昵称/头像；默认昵称 **`大厨` + 4 位大写字母数字**（见账号详细设计 §5.1）。
- openid **只存服务端** `user_identities`，不写前端日志与普通埋点。
- 确认页：时令主列表默认全选；四季常见默认计入且主列表不铺开；**调味不出现**；**拍照入口不展示**（见菜场输入详细设计 §2）。
- 食材 `cities: []` = 全国；本切片用户可无 `city`，列表走全国 fallback。
- 本切片 **不做**：场景表单、推荐引擎、进场确认、饮食记录、完整画像引导、流量主广告、美团日更、语音补菜（可留按钮占位但不必接通）。
- 目录约定：`miniprogram/`、`cloudfunctions/`、`data/`（见技术设计 §8.2）。

- [ ] **Step 3: 实现 `nickname.js`**

```js
'use strict'

const ALPHA = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789'

function hash32(str) {
  let h = 2166136261
  for (let i = 0; i < str.length; i++) {
    h ^= str.charCodeAt(i)
    h = Math.imul(h, 16777619)
  }
  return h >>> 0
}

/**
 * @param {string} uid
 * @param {number} [len=4]
 * @returns {string}
 */
function buildDefaultNickname(uid, len = 4) {
  let h = hash32(String(uid || 'anon'))
  let code = ''
  const n = Math.max(4, len)
  for (let i = 0; i < n; i++) {
    code += ALPHA[h % ALPHA.length]
    h = Math.imul(h, 1664525) + 1013904223
    h >>>= 0
  }
  return `大厨${code}`
}

module.exports = { buildDefaultNickname, hash32 }
```

```js
function truncateSeasonal(list, perCat = 8, maxTotal = 60) {
  const byCat = new Map()
  const sorted = [...list].sort((a, b) => (a.sort ?? 999) - (b.sort ?? 999))
  const out = []
  for (const item of sorted) {
    const c = item.category || 'other'
    const n = byCat.get(c) || 0
    if (n >= perCat) continue
    if (out.length >= maxTotal) break
    byCat.set(c, n + 1)
    out.push(item)
  }
  return out
}
```

- [ ] **Step 1: 实现 `cloudfunctions/auth/index.js`**

```js
'use strict'
const cloud = require('wx-server-sdk')
const { buildDefaultNickname } = require('../_shared/nickname.js')

cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV })
const db = cloud.database()

exports.main = async (event) => {
  const wxContext = cloud.getWXContext()
  const openid = wxContext.OPENID
  if (!openid) {
    return { ok: false, error: 'NO_OPENID' }
  }
  const platform = event.platform || 'mp'
  if (platform !== 'mp') {
    return { ok: false, error: 'UNSUPPORTED_PLATFORM' }
  }

  const idRes = await db.collection('user_identities')
    .where({ provider: 'wechat_mp', providerUserId: openid })
    .limit(1)
    .get()

  const now = db.serverDate()

  if (idRes.data.length) {
    const row = idRes.data[0]
    await db.collection('user_identities').doc(row._id).update({
      data: { lastLoginAt: now }
    })
    const userRes = await db.collection('users').where({ uid: row.uid }).limit(1).get()
    const user = userRes.data[0]
    return {
      ok: true,
      uid: user.uid,
      nickname: user.nickname,
      avatarUrl: user.avatarUrl || null,
      isNewUser: false,
      city: user.city || null
    }
  }

  const uid = `u_${Date.now().toString(36)}${Math.random().toString(36).slice(2, 8)}`
  let nickname = buildDefaultNickname(uid)
  // 可选：查重 nickname，冲突则 buildDefaultNickname(uid, 5)

  await db.collection('users').add({
    data: {
      uid,
```

### Task 8: 云函数 `ingredients.list`

**Files:**
- Create: `cloudfunctions/ingredients/index.js`

**Interfaces:**
- Consumes: `buildConfirmList`；云库 `ingredients`；可选 `event.city`，缺省读当前用户 `users.city`  
- Produces: `{ ok:true, seasonal, yearRound, fallback? }`

鉴权：用 OPENID 查 identity → uid（与 auth 相同模式）；读 users.city。本切片列表为只读主数据，仍建议登录后调用。

- [ ] **Step 1: 实现 list**

```js
'use strict'
const cloud = require('wx-server-sdk')
const { buildConfirmList } = require('../_shared/confirmList.js')

cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV })
const db = cloud.database()
const MAX = 500

exports.main = async (event) => {
  const wxContext = cloud.getWXContext()
  const openid = wxContext.OPENID
  if (!openid) return { ok: false, error: 'NO_OPENID' }

  let city = event.city || null
  if (!city) {
    const idRes = await db.collection('user_identities')
      .where({ provider: 'wechat_mp', providerUserId: openid }).limit(1).get()
    if (idRes.data[0]) {
      const u = await db.collection('users').where({ uid: idRes.data[0].uid }).limit(1).get()
      city = (u.data[0] && u.data[0].city) || null
    }
  }

  const res = await db.collection('ingredients').limit(MAX).get()
  const built = buildConfirmList(res.data, city)
  return { ok: true, ...built }
}
```

若数据量以后 >500，再加分页或云端筛选；MVP 静态库足够。
