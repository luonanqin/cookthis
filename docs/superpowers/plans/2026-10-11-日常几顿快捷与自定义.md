# 日常几顿：快捷 + 自定义 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 确认页日常「几顿」在 4 个预设芯片旁增加「自定义」弹窗（午/晚步进），按确认的 n/m 生成 `mealSlots`（先午后晚），提交时禁止自定义 0+0；聚会交互不变。

**Architecture:** 纯函数 `buildDailySlotsFromCounts` / `formatCustomChipLabel` 落在 `cloudfunctions/_shared/dailyMealSlots.js`（可单测），同步一份到 `miniprogram/utils/dailyMealSlots.js`（与 shoppingList 相同的 vendoring）。确认页只做 UI 状态与校验；云函数 `recommend.create` 将日常 `mealSlots` 上限放宽到 14。

**Tech Stack:** 微信小程序原生；Node `node --test`（`npm test`）；无新依赖。

## Global Constraints

- **仅日常**改几顿 UI；聚会仍 `bumpPartySlots` 1～7、`meal: other`。
- 步进：午、晚各自 **0～7**；合计 **≤14**；减到 0 不可再减。
- 弹窗首次打开固定 **午 0、晚 0**（不从当前快捷反推）；再次打开用**上次弹窗确认**的 n/m。
- 自定义确认后即使等于某预设，也**保持自定义高亮**，不自动切预设。
- 点回预设：写预设 `mealSlots`，自定义芯片文案恢复「自定义」。
- `mealSlots` 顺序：先全部午饭（`午饭①`…），再全部晚饭（`晚饭①`…）。
- 自定义 0+0 提交 toast：**「请先选择吃几顿」**，不调 `recommend.create`。
- 各顿仍共用当次一个 `combo`（不改）。

- [ ] **Step 3: 最小实现**

```js
'use strict'

function clampMealCount(n) {
  const x = Math.floor(Number(n))
  if (!Number.isFinite(x) || x < 0) return 0
  if (x > 7) return 7
  return x
}

function canIncrement(lunch, dinner, which) {
  const l = clampMealCount(lunch)
  const d = clampMealCount(dinner)
  if (l + d >= 14) return false
  if (which === 'lunch') return l < 7
  if (which === 'dinner') return d < 7
  return false
}

function buildDailySlotsFromCounts(lunchCount, dinnerCount) {
  const l = clampMealCount(lunchCount)
  const d = clampMealCount(dinnerCount)
  const slots = []
  for (let i = 0; i < l; i++) {
    slots.push({ meal: 'lunch', label: '午饭' + '①②③④⑤⑥⑦'[i] })
  }
  for (let i = 0; i < d; i++) {
    slots.push({ meal: 'dinner', label: '晚饭' + '①②③④⑤⑥⑦'[i] })
  }
  return slots
}

function formatCustomChipLabel(lunchCount, dinnerCount) {
  const l = clampMealCount(lunchCount)
  const d = clampMealCount(dinnerCount)
  if (l === 0 && d === 0) return '自定义'
  if (l === 0) return d + '晚'
  if (d === 0) return l + '午'
  return l + '午+' + d + '晚'
}

module.exports = {
  clampMealCount,
  canIncrement,
  buildDailySlotsFromCounts,
  formatCustomChipLabel
}
```

> 标签圈号：若环境对 `'①②③④⑤⑥⑦'[i]` 编码敏感，可改用数组 `['①','②',…][i]`。

- [ ] **Step 3: 弹窗开关与步进**

```js
onOpenCustomSlots() {
  const firstOpen =
    this.data.dailySlotMode !== 'custom' &&
    this.data.customLunchCount === 0 &&
    this.data.customDinnerCount === 0 &&
    this.data.customChipLabel === '自定义'
  // 定稿：首次进入固定 0+0；再次打开用上次确认的 n/m
  // 「再次」= 已有确认过的计数，或已是 custom 模式
  const useSaved =
    this.data.dailySlotMode === 'custom' ||
    this.data.customLunchCount > 0 ||
    this.data.customDinnerCount > 0
  this.setData({
    showCustomSlots: true,
    draftLunchCount: useSaved ? this.data.customLunchCount : 0,
    draftDinnerCount: useSaved ? this.data.customDinnerCount : 0
  })
},

onCloseCustomSlots() {
  this.setData({ showCustomSlots: false })
},

bumpCustomDraft(e) {
  const which = e.currentTarget.dataset.which // 'lunch' | 'dinner'
  const delta = Number(e.currentTarget.dataset.delta) || 0
  let l = this.data.draftLunchCount
  let d = this.data.draftDinnerCount
  if (delta > 0) {
    if (!canIncrement(l, d, which)) return
    if (which === 'lunch') l += 1
    else d += 1
  } else {
    if (which === 'lunch') l = Math.max(0, l - 1)
    else d = Math.max(0, d - 1)
  }
  this.setData({
    draftLunchCount: clampMealCount(l),
    draftDinnerCount: clampMealCount(d)
  })
},

onConfirmCustomSlots() {
  const l = clampMealCount(this.data.draftLunchCount)
  const d = clampMealCount(this.data.draftDinnerCount)
  const mealSlots = buildDailySlotsFromCounts(l, d)
  this.setData({
    showCustomSlots: false,
    dailySlotMode: 'custom',
    dailySlotPresetId: '',
    customLunchCount: l,
    customDinnerCount: d,
    customChipLabel: formatCustomChipLabel(l, d),
    mealSlots
  })
  track('scene_meal_slots_change', {
    meal_slots_mode: 'custom',
    lunchCount: l,
    dinnerCount: d,
    slots: mealSlots.length
  })
},
```
