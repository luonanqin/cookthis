# 已选方案按顿分组 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 已选方案页自产与分享卡按顿分组展示菜品，一顿也显示顿次标签。

**Architecture:** `listAccepted` 展平时为每道菜写入 `mealLabel`；小程序 `mapItem` 拼 `mealGroups`；WXML 按组渲染，扁平 `dishes` 保留给已吃/tip/分享。

**Tech Stack:** 微信小程序、云函数 Node、`node:test`

## Global Constraints

- 一顿也始终显示顿次标签；空 `mealLabel` 显示「本顿」
- 不改 tip / `onToggleDish` / 分享 / sticky meta / `omitSlots` 摘要
- 改 `_shared/listAccepted.js` 后必须 `cp` 到 `recommend/listAccepted.js`

- [ ] **Step 1: Add groupDishesByMeal + wire mapItem**

In `acceptedPlans.js` (near `mapItem`):

```js
function groupDishesByMeal(dishes) {
  const groups = []
  const indexByLabel = Object.create(null)
  ;(dishes || []).forEach((d) => {
    if (!d) return
    const mealLabel = d.mealLabel != null ? String(d.mealLabel) : ''
    if (indexByLabel[mealLabel] == null) {
      indexByLabel[mealLabel] = groups.length
      groups.push({
        mealLabel,
        displayLabel: mealLabel || '本顿',
        dishes: []
      })
    }
    groups[indexByLabel[mealLabel]].dishes.push(d)
  })
  return groups
}
```
