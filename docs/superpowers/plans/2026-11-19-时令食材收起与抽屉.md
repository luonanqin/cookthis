# 时令食材收起与抽屉 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 确认食材页时令默认一行半收起预览 + 抽屉点选；顶栏与四季常见展示已选/全量。

**Architecture:** 卡片预览用 `seasonalFlat`（按 `seasonalGroups` 展平）无框文本 + `max-height`/渐隐；完整分组芯片迁入底部 `mask`+`sheet`。选中仍写 `seasonalChecked`，预览不绑 `chip-on`。`_counts` 补 `seasonalTotal` / `yearRoundTotal`。

**Tech Stack:** 微信小程序 confirm 页；`node --test` 静态 wiring 测试。

**Spec:** [`../specs/2026-11-19-时令食材收起与抽屉-design.md`](../specs/2026-11-19-时令食材收起与抽屉-design.md)

## Global Constraints

- 预览点击只开抽屉，不 toggle 选中
- 收起预览无类别、无外框、无选中高亮
- 全选/清空仅在抽屉内
- 遮罩 +「完成」均可关抽屉；关抽屉不清空已选
- 不改四季常见 fold 交互，只改正文案为已选/全量
- 不改云函数与默认勾选规则

- [x] **Step 3: 实现 JS**

在 `groupByCategory` 旁增加：

```js
function flattenSeasonalGroups(groups) {
  const out = []
  ;(groups || []).forEach((g) => {
    ;(g.list || []).forEach((it) => out.push(it))
  })
  return out
}
```

`data` 增加：`seasonalFlat: []`, `seasonalDrawerOpen: false`, `seasonalTotal: 0`, `yearRoundTotal: 0`。

`_counts`：

```js
_counts(seasonalChecked, yearRoundChecked, manuals, lists) {
  const seasonal = (lists && lists.seasonal) || this.data.seasonal || []
  const yearRound = (lists && lists.yearRound) || this.data.yearRound || []
  const sc = countTrue(seasonalChecked)
  const yc = countTrue(yearRoundChecked)
  const mc = (manuals || []).length
  return {
    count: sc + yc + mc,
    seasonalCount: sc,
    yearRoundCount: yc,
    seasonalTotal: seasonal.length,
    yearRoundTotal: yearRound.length
  }
}
```

`_applyIngredientPayload`：先算 `seasonalGroups`，再 `seasonalFlat: flattenSeasonalGroups(seasonalGroups)`，`_counts(..., { seasonal, yearRound })`。

增加：

```js
onOpenSeasonalDrawer() {
  if (this.data.listEmpty) return
  this.setData({ seasonalDrawerOpen: true })
},
onCloseSeasonalDrawer() {
  this.setData({ seasonalDrawerOpen: false })
},
```

所有 `_counts(...)` 调用在 apply 路径传入 lists；toggle/clear 可依赖 `this.data` 已更新的列表。
