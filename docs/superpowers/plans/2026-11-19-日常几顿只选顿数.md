# 日常几顿只选顿数 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 日常「几顿」改为只选顿数：快捷 **1～5**；**自定义**需会员或（阶段 2）看广告后可选 **1～10**；去掉午/晚芯片与双步进；推荐页 / 已选方案 / 场景摘要只用「第N顿」「N顿」；会员权益增加「多顿」并排在广告上一档。

**Architecture:** 重写 `dailyMealSlots` 纯函数为 `buildDailySlotsByCount(n)`；确认页替换预设与弹窗；`recommend.create` 对非会员（无当日解锁）拒绝 `mealSlots.length > 6`；展示层统一中性 label。会员页权益文案与 [`2026-11-17-会员开通与权益`](./2026-11-17-会员开通与权益.md) 对齐增补。

**Tech Stack:** 微信小程序原生；`node --test`；现有 `callCloud` / `track` / membership `getStatus`。

**Spec:** `docs/superpowers/specs/2026-10-11-日常几顿快捷与自定义-design.md`（2026-11-19 修订）  
**勿用：** `docs/superpowers/plans/2026-10-11-日常几顿快捷与自定义.md`（午晚历史计划）

## 实现拍板

| 项 | 本计划选定 |
|----|------------|
| 快捷芯片 | `1顿`…`6顿`（id: `count_1`…`count_6`）；默认 `1顿` |
| 自定义上限 | **10**；免费硬顶 **5**（服务端） |
| `mealSlots` | `{ meal: 'other', label: '第1顿' … }` |
| 自定义门槛 | 会员 → 直接弹步进；非会员阶段 1 → 半屏主推开通会员（广告按钮可隐藏或灰态「即将支持」）；阶段 2 激励完播写 `dailyMealCustomUnlockDay` |
| 场景摘要 | `mealSlotsSummary` = `` `${n}顿` ``；回退勿 join 旧午饭标签 |
| 历史数据 | 展示时若 label 含「午饭/晚饭」或 meal 为 lunch/dinner，**归一**为第 N 顿（按数组下标） |

## Global Constraints

- 仅日常改几顿；聚会步进逻辑不改为 6/10（保持现网上限）。  
- 各顿仍共用一个 `combo`。  
- 提交至少 1 顿；自定义确认 0 不可（步进最小 1）。  
- 不恢复午晚快捷文案。

onOpenCustomMealCount() {
