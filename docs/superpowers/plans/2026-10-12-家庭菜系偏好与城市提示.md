# 家庭菜系偏好与城市提示 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 家庭级 `cuisinePrefs`（喜欢软加权 / 讨厌硬排除）接入推荐；引导与「我的」可编辑菜系；城市旁注「仅用于匹配当地常见食材」；菜谱补 `cuisineTags`（无标签不因菜系加减分）。

**Architecture:** 词表与 sanitize / 硬排除 / 软分纯函数放 `cloudfunctions/_shared/cuisinePrefs.js`（可单测）。`homePlans` 候选过滤加菜系 avoid，`softPenalty` 加 prefer 减分；`unconventionalPlans` 选菜同样硬排除。`profile` / `auth` 读写 `users.cuisinePrefs`。小程序引导多一步菜系、我的完整编辑；城市文案只改提示。菜谱用脚本按菜名关键词打 `cuisineTags`，再同步 builtin / for-import。

**Tech Stack:** 微信小程序 + 云开发；Node `node --test`（`npm test`）；无新依赖。

## Global Constraints

- 食材确认页货架 **仍只由城市决定**；菜系不改货架。
- 仅**家庭** `cuisinePrefs`；不做成员覆盖；轻量补全弹层**不收**菜系。
- 强度：`prefer` / `neutral` / `avoid`；未设 = `neutral`。
- 讨厌：**硬排除**（`cuisineTags ∩ avoid ≠ ∅` → 整道菜不进任何方案）。
- 喜欢：软加权（本计划：`softPenalty` **减 20**，与现有「分低优先」一致）。
- 用户可选词表 **19 个英文 code**（见设计）；**不**向用户展示 `home_style`。
- 无 `cuisineTags` 的菜：不因菜系加权或排除。
- 聚会：仍用家庭 `cuisinePrefs`（本场不另收）。
- 城市辅助说明固定文案：`仅用于匹配当地常见食材`。
- Vendoring：改 `_shared/homePlans.js` / `unconventionalPlans.js` 后必须同步到 `cloudfunctions/recommend/` 同名文件。

  { id: 'sichuan', label: '川菜' },
  { id: 'cantonese', label: '粤菜' },
  { id: 'shandong', label: '鲁菜' },
  { id: 'jiangsu', label: '苏菜' },
  { id: 'zhejiang', label: '浙菜' },
  { id: 'fujian', label: '闽菜' },
  { id: 'hunan', label: '湘菜' },
  { id: 'anhui', label: '徽菜' },
  { id: 'northeast', label: '东北菜' },
  { id: 'northwest', label: '西北菜' },
  { id: 'shanghai', label: '本帮/上海' },
  { id: 'beijing', label: '京菜' },
  { id: 'henan', label: '豫菜' },
  { id: 'yunnan', label: '云南菜' },
  { id: 'guizhou', label: '贵州菜' },
  { id: 'inner_mongolia', label: '内蒙菜' },
  { id: 'xinjiang', label: '新疆菜' },
  { id: 'hubei', label: '湖北菜' },
  { id: 'jiangxi', label: '江西菜' }
]

const CUISINE_CODES = CUISINE_OPTIONS.map((x) => x.id)
const FORM_VALUES = ['prefer', 'neutral', 'avoid']
const PREFER_DELTA = -20

function sanitizeCuisinePrefs(prefs) {
  const out = {}
  if (!prefs || typeof prefs !== 'object') return out
  for (const code of CUISINE_CODES) {
    const v = prefs[code]
    if (FORM_VALUES.includes(v) && v !== 'neutral') out[code] = v
    // neutral 可省略；若客户端显式传 neutral 也可写入，二选一：本实现省略 neutral 以省字段
  }
  return out
}

function familyAvoidCuisines(prefs) {
  const p = prefs || {}
  return CUISINE_CODES.filter((c) => p[c] === 'avoid')
}

function familyPreferCuisines(prefs) {
  const p = prefs || {}
  return CUISINE_CODES.filter((c) => p[c] === 'prefer')
}

function recipeBlockedByCuisine(recipe, prefs) {
  const avoids = familyAvoidCuisines(prefs)
  if (!avoids.length) return false
  const tags = (recipe && recipe.cuisineTags) || []
  if (!Array.isArray(tags) || !tags.length) return false
  const set = new Set(avoids)
  return tags.some((t) => set.has(t))
}

function cuisineSoftDelta(recipe, prefs) {
  const prefers = familyPreferCuisines(prefs)
  if (!prefers.length) return 0
  const tags = (recipe && recipe.cuisineTags) || []
  if (!Array.isArray(tags) || !tags.length) return 0
  const set = new Set(prefers)
  return tags.some((t) => set.has(t)) ? PREFER_DELTA : 0
}

module.exports = {
  CUISINE_CODES,
  CUISINE_OPTIONS,
  PREFER_DELTA,
  sanitizeCuisinePrefs,
  familyAvoidCuisines,
  familyPreferCuisines,
  recipeBlockedByCuisine,
  cuisineSoftDelta
}
```

function tagName(name) {
  const tags = []
  for (const r of RULES) {
    if (r.re.test(name || '')) tags.push(r.code)

  if (!tags.length) tags.push('home_style')

function patchFile(file, jsonl) {
  const p = path.join(__dirname, '..', 'data', file)
  if (jsonl) {
    const lines = fs.readFileSync(p, 'utf8').trim().split(/\n/)
    const out = lines.map((line) => {
      const o = JSON.parse(line)
      o.cuisineTags = tagName(o.name)
      return JSON.stringify(o)

    fs.writeFileSync(p, out.join('\n') + '\n')
  } else {
    const arr = JSON.parse(fs.readFileSync(p, 'utf8'))
    for (const o of arr) o.cuisineTags = tagName(o.name)
    fs.writeFileSync(p, JSON.stringify(arr, null, 2) + '\n')
  }
}

patchFile('recipes-builtin.json', false)
patchFile('recipes-for-import.json', true)
console.log('tagged recipes-builtin + recipes-for-import')
```
