# 会员开通与权益 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 上线可购买轻会员：单页展示权益/用量/套餐；虚拟支付闭环授会员；换菜日 3 服务端强制 + 触顶软挡（不挡去买菜）；日常总菜数免费软限 12。

**Architecture:** 新建云函数 `membership`（状态/下单/刷新/发货）；纯函数定价与额度进 `_shared`；`recommend` 的 `reject`（及兼容 `swap`）换菜路径扣日额度并返回 `SWAP_CAP`；日常 `create` 对非会员标 `softLocked` 超额菜。支付走微信**道具直购** `wx.requestVirtualPayment`（`short_series_goods`），**仅** `xpay_goods_deliver_notify` / `refresh` 查单后 `fulfillPaidOrder` 写权益。前端 `pages/membership/index` 一页；首页 VIP 在字号「大」左侧；「我的」资料区状态。

**Tech Stack:** 微信云开发 Node；小程序原生；`wx.requestVirtualPayment` + 云开发消息推送；`node --test`；现有 `callCloud` / `track`。

**Spec:** `docs/superpowers/specs/2026-11-17-会员开通与权益-design.md`  
**配套:** `doc/盈利模式方案.md`

## 实现拍板

| 项 | 本计划选定 |
|----|------------|
| 支付 | 米大师道具直购；每档 **首购/页价各一个** `productId`（共 6 个）映射在 `membershipCatalog.js`；密钥仅云函数环境变量 |
| 授会员 | **只**服务端 `fulfillPaidOrder`（回调或 refresh 查单）；前端 success **禁止**写会员 |
| 续费叠加 | 从 `max(now, expiresAt)` 起加时长（月 31 / 季 93 / 年 365 天） |
| 首购 | 以 `membership_orders` 曾 `paid` 的 sku 为准；`users.firstPurchaseUsed` 缓存加速展示 |
| 换菜池 | 自然日（**上海** `dayKeyChina`）免费 `used`；会员不扣；`rewardExtra` 字段预留阶段 2 |
| 激励视频 | 阶段 1 **不做**；触顶层仅「去买菜」+「开通会员」 |
| 菜数软限 | 日常非会员：累计菜卡 >12 的标 `softLocked:true`；聚会免检；不硬拦空白 |
| 开发授会员 | `action:devGrant` 仅当 `MEMBERSHIP_ALLOW_DEV_GRANT=1` |
| iOS | 若类目/虚拟支付未开通：会员页展示「当前环境暂无法支付」+ 引导安卓或客服；逻辑仍保留 |

## Global Constraints

- 不自动续费；不单开权益页。  
- 换菜触顶**禁止**清空方案或禁止进清单；主 CTA 永远是去买菜。  
- 阶段 1 权益文案**不写**「已免清单广告」。  
- 引导/onboarding **禁止**会员推销弹层。  
- 价格以分为单位整数运算，避免浮点。

**Collections:**
- `memberships`：`{ uid, tier, startsAt, expiresAt, updatedAt }`；每 uid **一份**当前态（`where({uid}).limit(1)`，无则 add）
- `membership_orders`：`{ orderId, uid, sku, amountFen, isFirstPurchase, productId, status, wxPayment?, createdAt, paidAt? }`

**`getStatus` 回包：**

```js
{
  ok: true,
  isMember: boolean,
  tier: string|null,
  expiresAt: string|null,
  expiresLabel: string|null, // YYYY-MM-DD 上海日
  swap: { used, limit /* member 时 limit:null */, rewardExtra },
  offers: [ buildSkuOffer(...), ... ],
  noticeAckRequired: true // 前端首次支付前
}
```

实现：读 `memberships` + `users.swapDaily` + 聚合该 uid `status=='paid'` 的 sku 集 → `firstPurchaseUsed`；可回写 `users.firstPurchaseUsed`。

**`createOrder`：**
1. 校验 `sku`  
2. `payFen = resolvePriceFen`  
3. `orderId` = 8–32 字符（如 `m` + uid 短码 + ts 进制）  
4. 写 `membership_orders` `status:'created'`  
5. 调 `xpay.buildVirtualPayParams({ orderId, productId, goodsPrice: payFen, openid, attach: orderId })`  
6. 返回 `{ ok:true, orderId, payFen, payment: { signData, paySig, signature, mode:'short_series_goods' } }`  
7. 若缺密钥：返回 `{ ok:false, error:'PAY_NOT_CONFIGURED' }`

**`xpay.js`（最小）：**
- HMAC-SHA256 按[虚拟支付签名详解](https://developers.weixin.qq.com/miniprogram/dev/api/payment/wx.requestVirtualPayment.html)生成 `paySig` / `signature`（实现时对照官方「签名详解」字段串；单测用固定 key 向量）  
- `queryOrder(outTradeNo)`：云调用或 HTTPS 查单（refresh 用）；未接通前可 stub 返回 null

**`fulfillPaidOrder({ orderId, wxPayment })`（幂等）：**
1. 读订单；已 `paid` → return ok  
2. 非 `created` → error  
3. 事务或条件更新：`status=paid`、`paidAt`  
4. 叠期写 `memberships`  
5. 更新 `users.firstPurchaseUsed[sku]=true`  
6. return `{ ok:true, membership }`

**推送入口：** `exports.main` 若 `event.Event === 'xpay_goods_deliver_notify'` → `fulfillPaidOrder({ orderId: event.OutTradeNo, ... })` → **必须** `return { ErrCode: 0, ErrMsg: 'success' }`（即使已发过货）。

**`refresh`：** 对最近未 paid 订单查单；若已支付则 fulfill；再 `getStatus`。

**`devGrant`：** 环境开关；`{ sku:'month' }` 直接 fulfill 模拟订单（status paid、amountFen 0、标记 `dev:true`）。

**鉴权：** 与其他函数相同：`cloud.getWXContext().OPENID` → `user_identities` → `uid`。

**支付：**

```js
onPay() {
  if (!this.data.noticeAcked) { this.setData({ showNotice: true }); return }
  const sku = this.data.selectedSku
  track('membership_pay_click', { sku, from: this.data.from })
  createOrder(sku).then((res) => {
    const p = res.payment
    wx.requestVirtualPayment({
      signData: typeof p.signData === 'string' ? p.signData : JSON.stringify(p.signData),
      paySig: p.paySig,
      signature: p.signature,
      mode: 'short_series_goods',
      success: () => {
        track('membership_pay_success', { sku })
        // 不授会员；轮询 refresh 1～3 次
        this._pollRefresh()
      },
      fail: (e) => {
        if (e && e.errCode === -2) track('membership_pay_cancel', { sku })
        wx.showToast({ title: '支付未完成', icon: 'none' })
      }
    })
  }).catch((err) => {
    wx.showToast({ title: (err && err.error) || '下单失败', icon: 'none' })
  })
}
```

`onLoad(q)`：`from = q.from || 'direct'`；`track('membership_page_show', { from })`；拉 `getStatus`。
